### 本轮（第 7 轮）之四：**打通惠州「民意直通车」—— 存量 2.4 万条（最大单市源）**

惠州互动页指向**独立域名** `www.hzhmsb.cn`（Spring Boot）。两个接口**都必须 POST JSON**：

```
列表  POST /portalweb/appealPublic/queryList.do   {"callType","pageNum","pageSize",…}
明细  POST /portalweb/appealPublic/getFormDetail.do {"formId","orderCode","ispublic",…}
```

**存量**：`callType=30` 局长信箱 **20,144** + `callType=29` 县区信箱 4,204。
**列表不含答复 ⇒ 必须逐条取明细**（0.55s/条）⇒ 分块跑。

**★ 两个坑（实测才发现）**：
1. 发表单编码被 Spring 的 `@RequestBody` 回 **415** ⇒ 必须 `Content-Type: application/json`。
2. **参数名不能猜** —— 猜 `sqly/pageIndex/pageSize` 时接口回
   `{"code":0,"desc":"操作成功","data":null}` —— **HTTP 200 + code:0 但空**，
   这是最容易骗过人的失败形态。真参数是从页面 JS 的 ajax 段抠出来的。
   ⇒ **「接口成功但 data 为空」= 参数名错，不是没数据。**

**质量**（首批 300 条）：投诉 97 / 咨询 78 / 举报 57 / 求助 48 / 建议 17 / 表扬 3；
答复**引用真实政策文号**（如「粤人社规〔2026〕20 号」）⇒ 高档考卷料。

## 四、验收条件（可执行）

**只有一条闸门。** Stop hook 是逐条独立执行 `- [ ] cmd:` 的，所以命令必须**自包含、并且用退出码表达成败**（不要 `$P` 这类变量、不要依赖上面另起一行的 `cd`）：

- [ ] cmd: bash "D:/AI/output/check.sh"

`output/check.sh` 内含 4 项硬判据，任一红即阻止会话停止：

| # | 判据 | 红意味着 |
|---|---|---|
| 1 | 数据总数 ≥ `.round-floor` | 有数据被删/损坏 ⇒ **先查清再继续** |
| 2 | 零数据适配器 = 0 | 有「建好没采」的源 ⇒ 先去跑它们 |
| 3 | 重复 id = 0 | 并发写污染 ⇒ 先去重 |
| 4 | 标签覆盖率 ≥ 90% | M3 未达标（当前 ~35.5%） |

> ⚠️ **不要再往这里加 `| head` / `| tail` 这类展示命令。** 管道会吃掉退出码，
> 让闸门永远返回 0 —— 旧版本就是这么失效的（6 条里 5 条永远"通过"，会话一轮就停）。
> 要加判据就写进 `check.sh`，那里是唯一以退出码说话的地方。

## 六、停止条件

**唯一允许停止的情况**：用户在会话里明确说停（或本文件顶部出现 `STOP` 标记）。

除此以外**一律不停**：活干完 → 扩面 → 扩不动 → 自检 → 自检完再重扫（判死清单可能因网站改版而失效，
旧判死要定期复验）。**这就是用户要的「一直跑」。**

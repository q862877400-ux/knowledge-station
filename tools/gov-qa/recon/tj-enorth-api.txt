天津 enorth「政民零距离」采集接口（2026-10-08 worker-breakthrough2 实测）
================================================================================

平台：北方网(ms.enorth.com.cn) 民生频道「政民零距离」＝ 天津官方网络问政平台
后端：津云网上问政中心 zw.enorth.com.cn/gov_open/

--------------------------------------------------------------------------------
一、入口与列表接口（★ 真正的分页接口）
--------------------------------------------------------------------------------
入口页   http://ms.enorth.com.cn/zmljl/                      -> 200（gb2312）
区县页   http://ms.enorth.com.cn/zmljl/quxian/<slug>/        -> 200，内嵌 iframe：
部门页   http://ms.enorth.com.cn/zmljl/bumen/<slug>/         -> 200，内嵌 iframe：

列表接口（iframe，HTML 表格，非 JSON）：
  GET http://zw.enorth.com.cn/gov_open/question/zero/list9a.jsp
        ?deptId=<deptId>&curpage=<p>&rows=<n>
  · curpage 1 起，rows 为每页条数（实测 rows=100 返回 100 条）
  · 实测 curpage=1/2/3 各 17 条，**两两 0 重叠** ⇒ 翻页正确
  · 页面含「共 N 条记录 第 X/Y 页 每页 rows 条」⇒ 可直接读总数
  · 每行： [类别] 标题(链接) 日期 回复 状态

明细接口（静态 HTML）：
  GET https://zw.enorth.com.cn/gov_open/<id>.html
  · 实测 **无需 Referer、无需 cookie**（带/不带均 200）
  · 页面含：标题 / 问题(发表人+提问时间) / 反馈(回复部门+回复时间) / 正文
  · 判「真问答」：含「发表人」且含「回复部门」

--------------------------------------------------------------------------------
· 近期活跃窗口内**近似连续**：区间 4753200..4753300（101 个 id）→ 200 命中 55、真问答 52（≈51.5%），
  其余为 404（空洞，非公开/已删）。
· **但全站 id 空间稀疏且非单调**：
    100000 -> 200（有内容）   4740000 -> 200   4752000 -> 200   4754420 -> 200
    4700000 -> 404            4750000 -> 404   4753500 -> 404   500000 -> 404
  ⇒ **区间扫只适用于「近期活跃窗口」，全量历史必须走 list9a.jsp 分页**（不要用区间扫代替分页）。

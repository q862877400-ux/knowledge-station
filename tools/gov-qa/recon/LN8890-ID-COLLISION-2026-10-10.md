# `ln-8890` 的 37 个"重复 id" —— **不是缺陷，是已正确处理的两个命名空间**（2026-10-10）

> 归属：Lead。**结论先行**：那 37 个 id 碰撞是**站方两个接口共用数字 id** 的客观事实，
> 而本模块**下游全部按 `(source, id)` 去重** ⇒ **已正确处理**，**不需要改**。
> ⚠ 我一度准备给 id 加 `kb:` 前缀并迁移 13,941 条数据 —— **已撤回**（见 §四）。

## 一、事实

`ln-8890` 与 `ln-8890-kb` 是**同一个站的两个接口**，但**共用同一套数字 id**：

| source | 接口 | 内容类型 |
|---|---|---|
| `ln-8890` | `/common/get_qa_byId?id=<n>` | 咨询投诉（`type=省直公积金`）|
| `ln-8890-kb` | `/common/knowledge/get?id=<n>` | 知识库（`type=民生知识热门问答`）|

**37 个 id 两边都有，内容完全不同**：

```
id=89659
  ln-8890-kb  民生知识热门问答  新参加工作或单位新调入的职工如何确定公积金缴存基数？
  ln-8890     省直公积金        如何申报2025年度个人所得税综合所得汇算清缴？
id=89953
  ln-8890-kb  民生知识热门问答  职工死亡后其合法继承人或受遗赠人如何提取住房公积金？
  ln-8890     省直公积金        提交个人所得税退税申请后税务审核通过了，但又发现申报错误，怎么办？
```

⇒ **不是采集器重复写，是站方两个 id 空间重号。**

## 二、为什么**不需要改**

### ① 下游全部按 `(source, id)` 去重（实测）

```
health.py:131                 key = (str(r.get("source") or "?"), str(r.get("id")))
recon/audit-coverage.py:248   key = (str(r.get("source") or "?"), str(r.get("id")))
```

两条记录的 `source` 不同 ⇒ **键不同** ⇒ 不会互相吃掉。

### ② `existing_ids` **没有漏读**（实测）

```
记录 21,748   不同 id 21,711   existing_ids 返回 21,711
记录里有、而 existing_ids 里没有的 id: **0**
```

⇒ `skip_ids` 是完整的，**增量轮询不会重复抓取**。

### ③ 全库同类的跨源 id 碰撞有 **10,337 个**，都是正常现象

```
全库记录 403,285   不同 id 391,461
同一 id 跨 ≥2 个 source 的: **10,337**
  top: ('gs-zhangye-23','xining-igi-43') 382 个
       ('baotou-igi-46','gs-zhangye-23') 311 个
       ...
```

不同站点各自的 id 编号**本来就可能相同** ⇒ 用 `(source, id)` 当键是**正确设计**。

## 三、★ 我自己在这里犯的错（记下来）

### 错误 1：**度量判据算错了**，得出"漏读 94.1%"的**假结论**

`recon/verify-idempotent.py` 之外的 `.tmp-idem-scope.py` 里我写：

```python
if len(existing_ids(k)) < 记录条数:   # ← 错
```

而 `existing_ids` 返回 **set**（去重）⇒ **只要有重复 id，`len(set)` 就必然小于记录数**。
那**不是"漏读"，是"去重后变少"**。

正确判据：**记录里出现过、但 set 里没有的 id 有几个**。

| 判据 | `ln-8890` 的结果 |
|---|---|
| `len(set) < 记录数`（**错**）| 报"漏 37 条" |
| `记录里的 id - set`（**对**）| **0 条** |

⇒ **修正后：全库 346 个通道，真的漏读 id 的 = 0 个。**

> ⚠ 注意：`poll.existing_ids` 那个**真 bug**（按 `source == channel_key` 过滤）
> **是另一件事、确实存在**（33 个通道读到 0）——那条已修（`cb1e46f6`），
> 与本节这个假象**不要混为一谈**。

### 错误 2：**没验证下游就准备改数据**

我看到"同 id 不同内容"就要加 `kb:` 前缀、还要迁移 13,941 条。
**改之前查了下游去重键**才发现：人家本来就按 `(source, id)` 去重 ⇒ **不需要改**。
`git checkout -- tools/gov-qa/adapters/ln_8890.py` 已撤回。

⇒ 纪律：**改数据之前先查下游怎么用**（"同 id 不同内容"是否真的有害，
取决于下游拿什么当键）。

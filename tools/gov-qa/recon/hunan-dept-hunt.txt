# ── 平台入口与 deptId 取法 ───────────────────────────────────────────────
# 接口（与 hunan-st / hunan-yj 同一平台）：
#   GET https://hd.hunan.gov.cn/communication/api-mailbox/frontMail/mailList2ie
#       ?data={"pageNum":1,"pageSize":M,"sortMap":{"createTime":"desc"},
#              "params":{"deptId":"<32位hex>","phone":"","searchCode":"",
#                        "status":"","siteNo":"","siteUrl":""}}
#   → {"status":"success","data":{"total":N,"pageTotal":…,"rows":[…]}}
# deptId 取法：进各厅局官网「互动交流」栏目页，其加载的
#   `/<站前缀>/xhtml/js/hdjl_index.js`（少数站把 deptId 内联在互动页 HTML）里
#   有 `var deptId = "<32位hex>"`。抠出后**立刻调接口**，data.total>0 才算通。

# ── 取法小结（一句话）────────────────────────────────────────────────
# deptId 就藏在各厅局官网「互动交流」页加载的 `hdjl_index.js`（或该页 HTML 本身）
# 里的 `var deptId = "<32位hex>"`；把 32 位 hex 塞进 mailList2ie 的 params.deptId，
# total>0 即通。绝大多数厅局域名形如 `<缩写>.hunan.gov.cn`、JS 在
# `/<缩写>/xhtml/js/hdjl_index.js`（缩写≠域名时需先抓首页找真实路径）。

## ★ 安阳市·政民互动 —— **已打通**（`ay-zmhd`，河南第 2 个可采市级源）

### 怎么找到的

首页侦察时发现 `/zmhd/hygq/` 页面里**直接写着接口**：

```javascript
$.ajax({ url: 'https://page.anyang.gov.cn/zwfw/leader-mail/list',
         type: 'post', data: { size: 10, page: this.data.currentPage, systemType: 0 } })
```

⇒ **POST 表单**，参数是 `size` / `page` / `systemType`（不是我第一版猜的
`pageNum`/`pageSize` —— 猜的两种都 405/500，**从页面 JS 抄才对**）。

### 站点事实

响应：`{"result":200,"msg":"成功","obj":{"datas":[...],
"pageNumber","pageSize","totalPage","totalRow"}}`

**每条记录自带问答全文**（`askContent` + `replyContent`）⇒ **不需要逐条取明细**
（这是本模块少见的"一次拿全"接口）。

`systemType` 三个非空分类（实测 `totalRow`）：

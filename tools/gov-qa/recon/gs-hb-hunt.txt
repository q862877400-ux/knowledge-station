一、甘肃（gansu.gov.cn）——逐项实测
--------------------------------------------------------------------------------

【门户 www.gansu.gov.cn】HTTP/HTTPS 均 **412**（瑞数动态防护，JS challenge）
  http://www.gansu.gov.cn/   -> 412  6318B
  https://www.gansu.gov.cn/  -> 412  6307B
  特征：响应头 `server: ******`；body 内联混淆 JS `$_ts.cd="..."` + `<meta content=".." r="m">`
        + `<script r='m'>`；set-cookie 一个 `HttpOnly` 长效 cookie（expires 2036）。
  ⇒ 这是**瑞数信息(RiverSecurity)动态防护**：需执行 JS 计算二级 cookie，纯 httpx 无解。
  cookie 重放实测：带首访 cookie 二次请求仍 412/6330B（未通过）。

【省直部门批量探测】全部 412（同一瑞数防护覆盖整个 gansu.gov.cn 主域）
  rst / sthj / scjg / gxt / czt / jyt / mzt / sjt / jgsw / swt / zrzy .gansu.gov.cn -> 412
  （另有 ybj/swj/fzggw/lyt/jrj/nyy/dsj/rlzy/gaj/spj/jtyst/wsjkw/lyj 等子域 DNS 不存在）

【省门户 IGI / WAS5 / jact 指纹】均 412（同域被拦）
  /IGI/nbhd/openGovmsgbox.do?method=listGovmsgboxs&siteId=&appId=  -> 412 6474B
  /was5/web/search?channelid=1                                      -> 412 6362B
  /jact/front/mailpubdetail.do                                      -> 412 6398B

【门户自定义 404 路径】/hdjl/ /zmhd/ 均 412（非真 404，被 WAF 拦）

【甘肃政务服务网 zwfw.gansu.gov.cn】**可达 200**（不同基础设施，无瑞数）
  http://zwfw.gansu.gov.cn/  -> 200 74752B  （站群 CMS：webgansushengzhengwufuwuwang）
  /zmhd/ 政民互动 -> 200 5592B，列出四个入口：
      szgs/hdjl/showIndex12345.do      （12345）
      szgs/hdjl/showIndex.do           （政民互动）
      szgs/hdjl/showIndexts.do?areaCode=6200000000   （投诉）
      szgs/hdjl/showIndexjy.do?areaCode=6200000000   （建议）
  ⚠ 实测以上入口 **302 到 zwfw.gansu.gov.cn/gsjis/... 统一身份认证平台-用户登录**
    （title=「甘肃省统一身份认证平台-用户登录」81270B）⇒ **需要登录账号**。
  ⇒ 甘肃政务服务网互动 **未通（需登录）**。

【甘肃信访局 www.gsxfj.gov.cn】**可达 200**（56780B，站群 CMS）
  导航里「网上投诉/建议征集/查询评价」全部指向
      https://www.gsxfj.gov.cn:8088/wsxf-online/  （Vue SPA「甘肃省网上信访受理平台」）
  /wsxf-online/ 及其子路径一律返回同一 index（6439B，#app 挂载点，接口由
      https://www.gsxfj.gov.cn:8088/wsxf-online/js/app.9bf1052d.js 驱动）。
  站内其余栏目（shizhengxinwen/gongzuodongtai/lingdaojiefang/gonggaogongshi 等）
      均为**新闻/通知类静态文章**，**无任何「信件选登/办理公开」问答列**。
  ⚠ 网上信访需登录 + 查询码 ⇒ 按判断标准第③条 **未通**。
  （注：wsxf.gsxfj.gov.cn 与 xf.gansu.gov.cn 均 DNS 不存在；只有 www.gsxfj.gov.cn:8088 在线）

【甘肃结论】**未通**。原因：整省主域被瑞数 412 拦死（门户+全部省直部门）；
  唯二可达的 zwfw.gansu.gov.cn（互动=SSO 登录）与 www.gsxfj.gov.cn（信访=SPA+查询码）
  都不满足「不需登录/查询码」。
  待登记 key 清单：无（未拿到任何可用问答源）。

三、瑞数 412 的处置备忘（给接手的人）
--------------------------------------------------------------------------------
· 甘肃全省、湖北门户根路径 = **瑞数动态防护**，纯 HTTP 客户端过不去（需 JS 引擎）。
· **但 IGI 路径 `/IGI/nbhd/openGovmsgbox.do` 在湖北/武汉门户被放行**（200）——
  这是本次最大的意外收获：WAF 只拦 HTML 页面路径，未拦该 JSON 接口。
· 结论：**遇到 412 省份，务必单独试 `/IGI/` 路径**，很可能接口层未被拦。
· 甘肃门户 `/IGI/` 实测仍 412 ⇒ 甘肃是整域拦截，无此例外。

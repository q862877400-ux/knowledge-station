平台：江苏省政府门户「互动交流 → 咨询建言」（https://www.jiangsu.gov.cn/col/col81602/）
      聚合各厅局**自己域名下部署的同款 jact 应用**（万户 hanweb 系，路径 /jact/front/）。
      每个厅域名单独部署、数据各自独立；同一域名下可有多个 sysid（不同栏目，实测两两不重叠）。

接口（详见 adapters/_jact_common.py 头注）：
  列表 POST https://<host>/jact/front/dataproxy_mailpublist.do
            ?startrecord=1&endrecord=19&perpage=19&groupSize=3
       body(表单) sysid=<n>&datadetailid=&dicvalue=&mailnumber=&querycode=&groupid=&
                  mailstate=&starttime=&endtime=&keyword=
       header Referer: https://<host>/jact/front/mailpublist.do?sysid=<n>
       → 返回 JS 文本（非 JSON）：totalRecord=..;dataStore=["<tr>…transactId=..</a>…", …]
  明细 GET  https://<host>/jact/front/mailpubdetail.do?transactId=<id>&sysid=<n>
       → HTML 表格（label 左 td / value 右 td）：标题 / 内容 / 提交时间 / 处理状态 /
         回复日期 / 内容回复(答复) / 答复单位。

sysid 来源：门户 col81602 的 jpage 数据（dataproxy.jsp 分页）里 <a href='...mailpubdetail.do?
transactId=..&sysid=..'> 抠出 host+sysid，再逐个实测（**不猜**）。

实现与验证
--------------------------------------------------------------------------------
· 基座 adapters/_jact_common.py：POST 列表 → 抠 `dataStore = [ … ];` 数组体 → `"([^"]*)"`
  取元素（元素双引号包裹、内部 HTML 只用单引号，实测无内部 `"` ⇒ 安全，**不 eval**）→
  transactId 从 `<a href='…transactId=..'>` 抠 → 逐条 GET 明细 → 逐 `<td>` 取文本、
  「标签 td 的下一 td 即值」→ 只收有「内容回复」的（未答复跳过）。clean() 先剥标签再
  html.unescape（与 bj_hdjl.py 同口径，答复常含 GB&nbsp;18596-2001 这类实体）。
· 28 个薄壳 adapters/js_*.py 全部 `import` 通过、SITE.key 与文件名一致。
· 端到端实测：js-sthjt(limit 4)、js-fzggw(limit 2)、js-czt2(limit 2) 均正常返回问答。
· 礼貌抓取：请求间隔 1.5s；wlt/190 报 521 即停该线，未重试。

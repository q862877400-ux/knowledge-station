安徽 / 辽宁 问答平台形态侦察（2026-10-08）
============================================================
目的：判断两省的「问答知识库 / 历史咨询服务」是不是"一套平台多厅局挂载"
（像湖南 / 贵州 / 吉林那样换一个部门标识就能扩），还是逐站独立 CMS。
方法：抓现有站（ah_sthjt.py / ln_sthjt.py 记录的入口）→ 找可替换的部门标识
（deptId / siteId / 栏目 id / 站点前缀 / moduleId / pageId）→ 换厅局试同接口。


============================================================
一、安徽 —— ✅ **是统一平台（全省站群共享知识库）**
============================================================
形态：安徽省级部门站是**集约化站群 CMS**。页面里有
  `data-setting="{siteId:6788031, platformCode:'anhui_szbm_5'}"`
⇒ 每厅是同一平台（`anhui_szbm`）下的一个 site（各自 siteId），**不是各家独立 CMS**。

★ 决定性证据：**全厅局共用一个「答问知识库」label**
  列表：`GET {任一厅域名}/site/label/8888?labelName=knowledgeBaseList&action=page`
        `&pageSize=200&pageIndex=N&categoryCode=&organDn=&wenda_keywords=`
  · 该接口**返回的是跨厅局聚合**：条目 href 指向不同厅域名
    （实测前 200 条覆盖 17 个厅：jx 54 / tjj 34 / mpa 22 / kjt 16 / jtt 15 /
      fzggw 9 / lyj 8 / zrzyt 8 / sthjt 8 / sft 6 / czt 6 / sgj 5 / ct 2 /
      yjt 2 / sjzyj 2 / dohurd 2 / lswz 1）；
  · `pageSize=200` 有效、`pageIndex` 翻页有效（page1=200, page2=200, page12=82）；
  · **共 2282 条**（响应内 "共收录常见问题 2282 条"、pageCount=229@pageSize10）；
  · label 在**任意厅域名**都可用（sthjt / jtt / lyj 均可；www.ah.gov.cn 返回 0）；
  · 明细为各厅自己的 `https://<dept>.ah.gov.cn/<hdjl|hdhy|zmhd|gzcy>/dwzsk/<id>.html`，
    模板统一 `问 【问题】 答 【答复】`（跨厅抽 6 个：lyj/fzggw/tjj/jtt/jx 解析成功；
    sft 那条答复是附件「点击查看」，属正常跳过）。
⇒ **结论：一条接口覆盖全省所有厅局**（同湖南统一平台的性质），**无需按厅局复制薄适配器**。

已落适配器：`adapters/ah_kb.py`（key `ah-kb`，kind api，level province）
  · 端到端实测 limit=8：取到 林业局 / 发改委(公管办/重点办/价格处) / 统计局 等真人问答，
    答复为官方办理答复（常点名依据，如《国家重点保护野生动物名录》《安徽扬子鳄国家级自然保护区管理办法》）。
  · 旧 `ah-st`（生态环境厅单站 145 条）可保留；`ah-kb` 是**全省口径**，二者有重叠。

待登记 key：
  "ah-kb": "adapters.ah_kb"


============================================================
二、辽宁 —— ⚠ **引擎全省共用，但问答按厅分模块 ⇒ 不是"换一个 id 通吃"**
============================================================
形态：辽宁省级部门站用 **eportal / easysite 站群 CMS**（页面 `<input id="contextPath" value="/eportal">`）。
每站有 `siteId`（如生态厅 `444d45d9143842d79170a09379d05764`）、每模块有 `moduleId` + `pageId`。

★ 关键实测 1：**moduleId / pageId 与 host 无关**（全局唯一）
  用生态厅「历史咨询服务」的 `moduleId=f3e565ad2f1648218bac992faf7ac04e&pageId=c441c2c3cafe47478cffbb9828914f88`
  分别在 sthj / kjt / czt 三个 host 请求 `/eportal/ui?currentPage=1&...`，
  **三者返回完全相同**（len=41661, hf_search_box=12, title「历史咨询服务」）。
  ⇒ `/eportal/ui` 是共享后端，模块由 moduleId+pageId 唯一确定，与站点域名无关。

★ 关键实测 2：但该模块内容是**生态厅专属**，非全省聚合
  解析该模块第 1 页 10 条，全是环保主题（噪声投诉、12369 热线、环评、煤改气锅炉…）。
  ⇒ 它是生态厅自己的「历史咨询服务」，**不是**全省问答库。

★ 关键实测 3：其他厅没有同款内联问答
  kjt / czt / slt / zjt 的互动/信箱页 `hf_search_box=0`、无「历史咨询」字样；
  各厅「厅长信箱列表」页有**各自不同**的 moduleId：
    kjt = 4e4f6ea46a1e41408fa63216dfdb68e8
    zjt = 71d45c9803674d25893c51af0d4d8eda
    czt = aecd812ec5864c489b906b1a98066186
  且这些是**标题列表**（需再抓明细），非内联问答。

★ 其他入口（均未通）
  · 部分厅把咨询指向 `https://www.lnzwfw.gov.cn/8890/…`（「12345 民心智慧听」）
    —— 页面仅 3432 字节、无服务端问答，是 **JS SPA**，未挖到公开问答接口；
  · 门户共享主机 `lnszf.menhu.cn` **本机 ConnectError**；
  · 省长信箱在 `http://218.60.149.163:8883/comp/szxx.html`（省本级，非厅局问答）。

⇒ **结论：辽宁是"引擎共用、内容逐厅独立"** —— 没有单一"全省问答"接口；
   扩厅局需**逐厅发现各自的 moduleId/pageId** 并各自解析（且多数厅非内联问答，要抓明细），
   **不属于"换一个部门标识即可扩一片"**。故本轮**未新建辽宁适配器**。
   · 可行的杠杆（供参考）：moduleId 与 host 无关 ⇒ 若枚举到某厅的"内联问答类" moduleId，
     可从任意 host 采；但需逐厅发现，工作量大，暂不做。

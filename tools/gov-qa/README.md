# 政务问答采集（`tools/gov-qa/`）

> **这个模块干什么用**：把**部委 / 省市**官网上的「公众问答 / 常见问题 / 留言答复」扒下来，
> 整理成**统一的记录格式**，再切成**两类资产** ——
> ① 点名的依据**在我们库里**的 ⇒ **可当考卷**（测检索准不准）；
> ② 点名的依据**不在我们库里**的 ⇒ **补料清单**（该补哪几类、各多少）。
>
> **这个页面就是交接说明。** 接手的人（要去扒**各省市**的那位）读这一页 + `SITE-REGISTRY.md` 就够了。

## 二、加一个新站点 = 写一个适配器（**不用改别的文件**）

### 第 1 步：写 `adapters/<你起的短名>.py`

```python
SITE = {
    "key": "hebee",                  # 短名，做文件名与去重前缀
    "name": "河北省生态环境厅",
    "kind": "api",                   # api | static
    "level": "province",             # national | province | city
    "entry": "https://.../hdjl/",
    "status": "todo",                # ok | blocked | todo | chat_only
    "note": "怎么取到的，一句话",
}

def harvest(fetch, *, limit=None) -> list[dict]:
    rows = []
    r = fetch("https://.../api/list", params={"page": "1", "size": "100"})
    for it in r.json()["items"]:
        rows.append({...})           # ← 统一记录格式，见下
    return rows
```

### 第 2 步：在 `adapters/__init__.py` 的 `ADAPTERS` 里加一行

```python
ADAPTERS = {
    "mem": "adapters.mem_gov",
    "mee": "adapters.mee_gov",
    "hebee": "adapters.hebei_mee",      # ← 加这一行
}
```

**就这么多。** `harvest.py` 会自动认到这个站。

### 统一的记录格式（**必须逐字段对齐**）

```json
{
  "source": "mee",                    // = SITE["key"]
  "id": "1791251",                    // 站内唯一 id（去重靠它）
  "url": "http://.../t20260116_1140853.shtml",
  "question": "关于十三五期间环保政策文件是否有效的咨询",
  "answer": "《生态环境部行政规范性文件制定和管理办法》适用于……",
  "asked_at": "2025.10.24 08:05:00",  // 可 null
  "answered_at": "2025.10.27 11:04:00",  // 可 null
  "dept": "办公厅",                    // 回复单位，可 null
  "channel": "常见问题",                // 站内栏目名，可 null
  "extra": {}                         // 站点特有字段原样留着，别丢
}
```

⚠ **`answer` 必须是答复原文**，**不要清洗、不要摘要** —— 下游靠它抽出"点名了哪些文件"，
一摘要就把依据抹掉了。

## 三、三条踩过的坑（**别重踩**）

### 坑 1：`NO_PROXY` 里的 `[::1]` 会把 httpx 直接搞崩
本仓 G27。`NO_PROXY` 含 `[::1]` 时，httpx 0.28.1 **连 `Client()` 都构造不出来**
（`InvalidURL: Invalid port: ':1]'`）。`harvest.py` 开头已就地修成 `::1`，**你自己的脚本也要修**。

### 坑 2：**代理不是原因，别在代理上浪费时间**
业主一直开着代理（`http://127.0.0.1:7897`）。我实测过两条路：

| 站点 | 走代理 | 直连（`trust_env=False`）|
|---|---|---|
| 卫健委 `www.nhc.gov.cn` | 412 | **412** |
| 消防局 `www.119.gov.cn` | 405 | **405** |
| 住建部 | 200 | 200 |

**两条路一模一样** ⇒ 412 是**站点反爬**、405 是**路径/方法不对**。
**问题不在网络，在"地址不对"。**（卫健委真正的入口在**另一个域名** `zwfw.nhc.gov.cn`。）

### 坑 3：调用接口**必须带 `channelid`**，否则连能用的站也返回空页
我拿生态环境部已验证可用的 `/was5/web/search` 去试别的部委，**不带 `channelid`**，
结果包括**生态环境部自己**在内全都返回 **711 字节空页** ⇒ 那个测试**证明不了任何事**。
**别据"不带参数返回空页"判定某个站没有这个接口。**

## 四、★ 最重要的一条事实：**考卷做不大的瓶颈是"库"，不是"采集"**

2026-10-07 实测（生态环境部 158 条）：

| 量 | 值 |
|---|---|
| **可定位率**（答复点名了文件或标准号）| **134 / 158 = 85%** |
| **在库率**（点名的文件在我们库里）| **36 / 244 = 15%** |

⇒ 答复点名的 244 个文件里，**208 个不在我们库**。

**所以：继续爬部委是收益递减** —— 爬得再多，能当考卷的还是那 30 来条，
**其余全进"补料清单"**。要真正把考卷做大，得**先把库补上**（缺的是一整层**部门规章 / 省市规范性文件**）。

这条与另外两处观察**互相印证**：① 11 条真问题体检；② 法规层缺口 1,475 部。

## 六、边界（**做之前先看这一节**）

1. **礼貌抓取**：请求之间 `sleep ≥ 1.5s`；能用接口就别逐页爬；**这不是镜像工具的入口**，
   目标是取"问答文本"当语料。
2. **只写 `data/`**：本模块**不碰数据库、不碰生产件**。
3. **省市站先照 `SITE-REGISTRY.md` 的清单试**，别从零摸。省市的政府站**大量使用同一套中间件**
   （WAS5 等），**找到一个就等于找到一片**。
4. **问答站分两种**：**列表型**（能当考卷）与**聊天机器人型**（如市场监管总局的 `gjjly`，
   页面是对话气泡）—— **后者对做考卷没用**，识别方法见 `SITE-REGISTRY.md`。

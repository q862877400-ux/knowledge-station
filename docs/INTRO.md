# 法规标准智能工作站 —— 让每一句合规结论，都有法可依

> 面向中国国家标准与法律法规体系的 **取证式 AI 知识工作站**：把数万本国标与法规建成可检索、可引用、可自动跟踪效力的本地知识库。任何合规问题得到的，是一份「依据原文 + 推导过程 + 效力状态」的可审计答案，而不是大模型的流畅编造。

---

## 一、我们解决的问题

**企业合规与安全生产管理中最贵的成本，不是"查不到"，而是"查不准"和"不知道它已经改了"。**

- 引用已废止的标准，意味着整改方案从根上失去可信度——在安全生产、消防、危化、环保、工程质量这些被强监管的领域，一次错引可能直接转化为监管处罚、安全事故追责甚至诉讼败诉。
- 通用 AI 助手在法规场景是**危险的**：它会流畅地编造条款号、把废止版本和现行版本混为一谈。法规的精确性要求每一个数字、条款号、生效日期、适用条件都必须**逐字可验**。
- 中国标准法规更新极快、渠道极分散：国标委、应急管理部、住建部、生态环境部……各部委各自发布公告，人工跟踪必然漏检。据行业惯例，一家中型企业的合规团队每月要投入大量工时在"确认某标准是否还有效"这类低价值但高风险的核查上。

## 二、为什么是现在

生成式 AI 第一次让「用自然语言查询法规、直接产出可交付文档」成为现实；同时，幻觉问题让「取证式架构」从加分项变成硬门槛。**合规数字化（EHS、安全生产、企业合规）正从"制度模板库"升级为"智能体 + 法规知识底座"**——而知识底座的质量，取决于对中文法规语料的深度结构化能力，这正是我们的核心壁垒。

## 三、我们做了什么

一个已经全链路跑通的产品，而非演示：

| 能力 | 说明 |
|---|---|
| **取证式 AI 问答** | 回答强制三段式：**依据（真实条款原文）→ 推导（逻辑链，逐句挂证据）→ 结论**。每条证据可一键跳转官方原 PDF 的对应页码与条款位置。 |
| **防幻觉自动核验** | 内置三型核验器：数值篡改（40t 写成 4t 即拦）、模态强度（把"应"弱化为"宜"即拦）、法理要素（例外与主体丢失即拦），外加条款号闭包（回答引用的条款必须真实存在于证据集）。不是"提示词祈祷"，是工程拦截。 |
| **效力状态四色体系** | 每份标准标注 🟢现行可引 / 🟡即将实施 / 🔴被替代·已废止 / ⚪状态未知，单一真源 + 到期自动翻转——引用层只允许现行版。 |
| **官方公告自动巡检** | 每日自动访问十余个官方渠道（国家数字标准馆、国标委、政府公告、应急部/住建部等部委公告），发现新版/废止/替代即三色报告 + Excel 导出；支持用户自定义公告源持续监听。 |
| **本地优先双栏工作站** | 左栏文件目录（按国标 CCS 分类体系）、条款级全文检索、PDF 逐页跳转与条款级定位；收藏、批注、义务清单、检查表、效力报告一屏可及。 |
| **自动产出文档** | 合规审查报告（Word）、效力报告（按国标分类体系的 Excel）、义务清单与检查表、公告发现台账——从"问答"直接到"交付物"。 |

## 四、关键设计决策（落地可信度的来源）

1. **取证优先于生成**：答案结构、证据格式、核验规则都是硬约束，模型只负责在约束内组织语言。
2. **效力状态 = 数据而非描述**：被替代、废止、即将实施是结构化的生命周期数据，与条款本体、变更历史在同一时间轴上；审计时能看到"这份标准 2026 年因新版发布被标记废止，证据链在此"。
3. **来源白名单**：正文只来自官方渠道（国标委、国家法律法规数据库、各部委公告），每一份文档带来源、下载指纹与溯源链——满足最严格的合规审计要求。
4. **数据主权**：核心能力纯本地可运行、可离线，法规库与问答引擎部署在企业内网——对国企、监管机构与安全敏感行业是必要条件而非卖点。
5. **万级规模预留**：从单文档解析到批量入库、分页接口、增量索引均按"数万本、百万级条款"设计，而非演示级玩具。

## 五、落地证据（不是 PPT）

- **工程纪律可审计**：596 个自动化测试全绿合入门禁，检索质量有 96 条人工标注的评测集把关——每一轮功能合入都有量化回归，这在 AI 初创里少见。
- **全链路真实跑通**：代表性国标（如 GB 30871《危险化学品企业特殊作业安全规范》）从 PDF 深度解析 → 条款级结构化 → 混合检索 → 取证问答 → PDF 页码级定位，端到端无断点。
- **自动巡检真实出成果**：每日巡检在真实库中标记出「GB 24276-2017、GB/T 1019-2008 已被废止」，生成三色报告与 Excel——不是演示数据，是引擎自己从官方渠道抓到的真变化。
- **公告监听真实有效**：解析应急管理部官网公告列表，2021–2026 年间数十条官方公告完整入库去重、按发布日期正确排序——对部委网站的反爬、JS 渲染、噪声链接做了工程化处理。
- **核验器真拦真事**：实测中核验器对"吊装作业分级"答案完成三重校验——PDF 数字提取伪影下的边界值（40t/100t）、条款引用闭包、模态强度，全部自动判定，拦截项逐项清零后才放行。

## 六、差异化（与三类对手正面划界）

- **vs 通用大模型**：不编造、可溯源、守现行。通用模型给"参考性答案"，我们给"可签字答案"。
- **vs 通用 RAG 框架**：法规不是"文档"，是**带生命周期的强制规则**。我们做的是条款级解析 + 效力时间轴 + 语义化核验——通用框架在此三类能力上均为空白。
- **vs 传统合规软件**：制度模板库升级为"能对话、能追问、能自动跟踪更新"的知识智能体，把审查从"翻阅"变成"对话式核对"。

## 七、技术底座（一段话说清）

中文语料深度结构化管道（PDF 版面还原 → 条款切分 → 行级坐标 → 全文 + 向量双索引）；融合检索（分词全文检索 FTS5 + 本地语义向量，百万级条款毫秒级召回）；文档级与条款级双重重叠解析；本地向量数据库 + 单写者队列的一致性保障；全部基于成熟的本地基础设施（无云依赖、无外部 API 配额风险），可离线、可私有化。

## 八、里程碑与路线

**已交付**：取证问答、三型核验、效力四色体系、每日官方巡检、公告发现、义务清单/检查表、效力报告、Word/Excel 交付、本地双栏工作站、批注与收藏协作面。

**正在打磨**：万级语料批量导入与运维、效力报告/审查报告的高级形态、更多行业垂直包。

**规划**：监管侧上报模板、跨部门合规工作流、面向具体行业（化工、建筑、消防、环保）的预置知识包与场景化智能体。

## 九、商业化路径

- **订阅制桌面/私有化工作站**：按席位 + 行业知识包订阅，先验证付费意愿。
- **行业垂直包**：化工安全、建筑施工、消防工程、环保合规——把行业最痛的标准组合做成开箱即用包，一个行业就是一条独立收入线。
- **嵌入与被集成**：作为合规 SaaS、EHS 平台、大模型应用的知识底座对外提供能力（提供防幻觉取证问答接口）。

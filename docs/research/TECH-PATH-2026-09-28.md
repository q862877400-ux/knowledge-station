## §5 我们**独有的**那一条（第三栏）

**全场的记忆/检索系统里没有、而我们有的**（这是"三栏"的第三栏，不是自我表扬，是差异化事实）：

1. 🔴 **效力由发布机关决定**（现行/废止/即将实施），**不是"谁记得更晚谁赢"**。
   全场（graphiti / Zep / PPMF / MAP-Graph / mem0 / Hindsight）**都是 recency 或语义相似度**；
   Hindsight 甚至是 "new fact supersedes old"。**我们是唯一有"权威来源"这一维的。**
2. 🔴 **派生的失效必须记"谁说它失效了"**。全场**只记"失效了"、不记是谁说的**；
   PPMF 证明这不是洁癖——LLM 归并中一条低信任外部观察会被改写成"看起来像用户历史"（ASR 1.000）。
   ⇒ 我们的 `invalidation_source` + `material_review` 两列、**平台维护、模型不可改**，是**结构性优势**。
3. 🔴 **原文冗余锚点**（`quote_exact`）—— 全场没有；且 W3C 规范**自己说编号脆、原文稳**，与我们的直觉相反。
4. 🔴 **"未批准材料不进检索、不进结论"** 的硬门 —— 全场没有（Zeta Alpha 是"记忆无上限常驻、默认全注入"）。

⚠ **但第 4 条也是我们的负债**：Zeta Alpha **没有**提问记录层、**没有**失效机制、记忆**无上限常驻且不公开任何阈值**
⇒ 我们的候选层在商业产品里**确无对应物（利好）**，**但市场也没证明它有价值（风险）** ⇒ **支持先做最小可查询集**。

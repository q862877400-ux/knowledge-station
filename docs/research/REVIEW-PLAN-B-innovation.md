## 0. 业主真正要解决的问题（原话，不是转述）

> 「我感觉他这个结构是把知识库、skill 统一起来管理了，我们现在没有，真的没有价值吗？」
> 「我想要的就是，把那些权威的资料，包括一些项目文件什么的，全都存到一个知识库里面……
>  而他发现自己需要这个过程，其实就是一个检索的过程——不然他都不知道有这个知识的存在，
>  他怎么会去发现自己需要呢？」
> 「就比如说我想让你去开发一个项目，忽然想到我 20 年前另一个项目可以左位移个组件用起来……」
> 「如果我死了，子代理也停了……你看下对话记录看看我们的开发进行到哪里了，列个后续开发计划」

**硬约束（业主 2026-09-21 亲下的）**：
- **必须泛化**，针对各种资料都能用（技术文档、论文、古籍、教程），不只是法规。
- 答案要**条款级可点引用**（标准号 + 条款号 + 原文锚点）。
- **效力由发布机关决定**（现行/废止/即将实施），不是"谁记得更晚谁赢"。
- **材料评审三态硬门**：未批准材料不进检索、不进结论、不进产出物引用。
- 目标规模 **10⁶–10⁷ 条**。

## 2. ⚠ 现有那份"技术路径"说了什么（**你要审的是它**）

`docs/research/TECH-PATH-2026-09-28.md`，一句话版本：

> **别把"记忆"塞进检索里。** 原文层不动，把"谁问过/哪条答的/结论有没有被推翻"做成窄的派生层；
> 而检索质量的战场在**缩小候选集**，不在加检索路、不在调相似度。

三条支撑它的实测（**都标了【我实测】**）：
1. 不随 N 涨的两路（0.1 / 35.6 ms）才是扛得住规模的那两路；
2. 42,181 个术语里选对术语：**前 20 = 21.0%、前 50 = 33.0%**；**但"500 候选"口径下前 20 就 99.0%** ⇒ 它据此断言"瓶颈是候选集太大、不是排不上来"；
3. 官方 ANN 是**常数加速**（改系数不改复杂度）⇒ 今天能白拿 2.2×，但**不解除规模天花板**。

`docs/research/DECISION-TABLE-2026-09-28.md` 是 13 个战场的三栏表（抄哪一处 / 不抄哪一处 / 我们独有的）。

## 3. 🔴 我自己知道的最硬的一处伤 —— **请优先打这里**

第 2 条支撑里有个**逻辑漏洞**：

> "500 候选口径下前 20 = 99.0%" 是用**一个由答案本身构成的候选池**量出来的
> （`scripts/measure-term-selection.py` 的 docstring 逐字：「500 = 说法文件里出现过的那些术语，
> **就是那 500 个答案术语本身**，最乐观上界」）。

**这意味着"候选集缩小 84 倍 → 准确率到 99%"是 oracle 结果，它完全不能推出
"一个不知道答案的抽取器能做到"。** 而整条路的下一步正是"做抽取器"。

⇒ **请独立判断**：
- 这个 oracle 对照**到底能支撑多强的结论**？是不是被我当成了比它实际更强的证据？
- **有没有一种非 oracle 的实验**能回答"抽取器能把 42,181 缩到多少、还保住召回"？
  如果有，**设计它**（数据、命令、判据、成功/失败的阈值）。
- 如果这条路线的核心证据是循环的，**它的可信度还剩多少**？

## 6. 环境坑（省你时间；只限这些，其余自己踩）

- `clause_vec` 是 vec0 虚拟表，读它**必须** `sqlite_vec.load(conn)`，否则 `no such module: vec0`。
- `scripts/measure-term-selection.py` 用**现成向量缓存**（`var/tmp/term-index-full.json`，492 MB），
  没有会现场重建（约 531 s）；评测集在 `var/tmp/lay-50.jsonl` 等处，**先 `Get-ChildItem var\tmp -Recurse -Filter *.jsonl` 找全**。
- PowerShell：`if` 不能内联当表达式；`cd` 不更新进程 CWD ⇒ 写文件用绝对路径；
  `Select-String` 命中 minified JSON 会炸输出 ⇒ 先 `-List`。
- Python 里嵌 ASCII 双引号会 `SyntaxError` ⇒ 内层用「」或单引号。
- `node scripts\ui-render-shot.mjs --interact <x>` **会挂起不退出**，别在上面耗时间。
- `tsc` 对 `@deepseek-ai/*` 报的一堆错是**噪音**（包不在 node_modules，走白名单由 DSH 运行时提供）。
- 门禁：`pwsh -File scripts\run-gates.ps1 -Quick`；只看 `%TEMP%\ks-gates-last.txt` 摘要，别读 80 KB 日志。
- **工作区有别人的未提交改动**（`plugin/src/*.bak-20260927-*`、`tests/test_jev_cn_baseline.py`、
  `pelican-bike.html`）⇒ **别删、别 checkout、别 add**。
- arXiv 官方 API 本机**曾持续 429/406** ⇒ 抓不到时改用 `arxiv.org/abs/<id>` 官方页或
  `https://ar5iv.labs.arxiv.org/html/<id>`，并**逐字核标题**（本项目已发生两例"抓到了≠抓对了"）。

# 我们当前未解的问题：外部解法调研

> **为什么有这份**（业主 2026-09-27 原话）：「我们的任务不是继续开发了，而是把我们目前遇到的问题去搜去找，
> 找 Github 开源项目，找 Ai 相关的论文，穷尽可能地去寻找解法」。
>
> **这份文档的定位**：**只回答一个问题 —— "别人怎么解我们这个问题"。**
> 我们自己的事实（做成了什么、为什么这么做、哪条被否决）**不在这里**，在各自的归属层。
> 本文件里出现的每个数字都**指向它的归属层**；本文件自己的产出只有 §2–§8（外部解法 + 对策）。
>
> **纪律**：① 证据分级（独立第三方/论文自报/厂商自报/官方文档/我们的推断）逐条标；
> ② 关键数字回一手件核（arXiv 原文 / 官方文档页 / issue 原文），引用前**逐字核标题**
> （本项目曾有 4 个 URL 全部 200、结果是另外的论文）；③ 找不到就写"没找到"并写清搜过什么；
> ④ **不许拿二手博客/内容农场当依据**；⑤ 结论分「依据 / 推导 / 结论」三段。

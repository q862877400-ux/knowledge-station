## 1. 档位口径（读文档时必须先懂这个）

那三份文档用四个标签标证据强度，**这是本次核查的核心**：

| 标签 | 含义 |
|---|---|
| **【我实测】** | 上一个 AI 自称在本机跑出来的 |
| **【代理实测】** | 子代理跑的，它只核了一部分 |
| **【转述】** | 论文/官方文档数字，**它没复现** |
| **【推断】** | 它的判断，无实验 |

业主口径的三档映射：**已实测 = 【我实测】+【代理实测】**；**需实测 = 【转述】**；**纯推断 = 【推断】**。

⚠ **你最该盯的就是标签有没有标错**。把「转述」的东西写成「实测」、或把「推断」写成结论，
是这份产物最严重的失败模式。

## 2. 你要做的核查（逐条给证据，不要笼统说"没问题"）

### A1 · 重跑它的五个证据脚本，看数字是否复现
命令（在仓库根跑，用 `.venv` 的 python）：

```powershell
.venv\Scripts\python.exe scripts\probe-recall-latency.py        # 声称：向量 606.0ms / FTS 35.6ms / 精确条款号 0.1ms @522,021 行
.venv\Scripts\python.exe scripts\verify-dup-vectors.py         # 声称：唯一向量 490,017、冗余 32,004（6.13%）
.venv\Scripts\python.exe scripts\verify-dup-safety.py          # 声称：跨文档 9,506/10,060 组 ⇒ 去重不能做
pwsh -NoProfile -File scripts\pssa-guard-selftest.ps1          # 声称：8 passed / 0 failed
.venv\Scripts\python.exe scripts\measure-term-selection.py var\tmp\lay-50.jsonl
                                                          # 声称：全库前20 21.0% / 前50 33.0%；500口径前20 99.0%
```

**逐个核对**：跑出来的数与文档里写的**是否一致**（允许 <5% 的机器抖动，**但要写明你实测的值与它的差**）。
任何一个对不上，**就是一条硬错误**，写清是哪个数字、文档哪一行、你的实测值。

⚠ 这些脚本**只读**生产库，**不要**改成写。`clause_vec` 是 vec0 虚拟表，读它必须先
`sqlite_vec.load(conn)`，否则报 `no such module: vec0`（这是已知坑，不是 bug）。

### A2 · 逐条查「【我实测】」是否有据可查
在 `DECISION-TABLE-2026-09-28.md` 里数出所有标 **【我实测】** 的行（应约 13 行），
对每一行问：**这个数是哪个脚本/哪条命令产出的？文档里指出来了吗？**
- 指出来了 ⇒ 核那条命令能不能复现（A1 已做大部分）；
- **指不出来 ⇒ 标为"无据"**，这是严重问题。

### A3 · 查「转述」有没有被当成结论用
通读三份文档，找出**把外部论文数字当成本项目依据**的地方。重点看
`DECISION-TABLE` 的"不抄哪一处"列——那些理由是外部实验结论，
问：**这些结论的适用条件与我们场景是否匹配？**（例如 CAR 是靠 CVE 这类规整 ID 构造问题的，
我们的国标条款句式未必规整——文档自己承认了这点吗？）

## 3. 环境坑（省你时间，但**只限这些**，其余自己踩）

- PowerShell 里 `if` 不能当表达式内联（`(if(...){'a'})` 会报错），要先赋值再用。
- `Select-String` 命中 minified JSON 会炸满输出 ⇒ 先 `-List` 或排除 `json`。
- `cd` 不更新 PowerShell 进程的 CWD ⇒ 写文件用**绝对路径**。
- `node scripts\ui-render-shot.mjs --interact <x>` 会**挂起不退出** ⇒ 别在这上面耗时间。
- `tsc` 对 `@deepseek-ai/dsh-client-ui-primitives` 报的一堆图标错是**噪音**
  （该包在 `node_modules` 里根本不存在，走白名单由 DSH 运行时提供）⇒ **真判据是 `ui-render-shot`**。
- 门禁一条命令：`pwsh -File scripts\run-gates.ps1 -Quick`；**结果只读** `%TEMP%\ks-gates-last.txt`
  （0.8 KB 摘要），**别去读 80 KB 的日志**。
- **工作区里有别人的未提交改动**（`plugin/src/*.bak-20260927-*-before-v4-source`、
  `tests/test_jev_cn_baseline.py`、`pelican-bike.html`）⇒ **别删、别 checkout、别 add**。

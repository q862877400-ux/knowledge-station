## 2. ⚠ 必须先读的三条前提（不知道会做错方向）

### 2.1 我们的场景约束（判断"能不能抄"必须代入）

- **中文法规/国标为主**，但业主要求**必须泛化到任意资料类型**（技术文档、论文、古籍、教程）。
- 答案必须**条款级可点引用**：标准号 + 条款号 + 原文锚点。
- **效力由发布机关决定**（现行 / 废止 / 即将实施），**不是"谁记得更晚谁赢"**。
- **材料评审三态硬门**：未批准材料不进检索、不进结论、不进产出物引用。
- 技术栈：**单库 SQLite + `sqlite-vec` 的 `vec0`、512 维、Windows 单机、Python 引擎 + Node/React 插件**。
  **不要引守护进程**（不引 Postgres / Qdrant 服务），**不为这件事换栈**。
- 规模现状：**6,797 篇 / 522,021 条条款 / 2,246 MiB**；目标 **10⁶–10⁷**。

### 2.2 纪律（本仓规矩，违反即作废）

1. **证据分级逐条标**：①独立第三方/同行评审 ②论文自报 ③厂商自报 ④官方文档/官方仓库 ⑤你的推断。
   **厂商自报必须单独标注**，不许与①②混写。
2. **关键数字回一手件核**（arXiv 原文 PDF/abs、官方文档页、GitHub issue 原文）。
3. **"抓到了 ≠ 抓对了"**：引用前**逐字核标题**。
   ⚠ 本项目已发生两例：① 4 个 URL 全部 200、结果是**另外的论文**；
   ② 搜索引擎把 EMNLP 2024《Focused LLMs are Stable Many-Shot Learners》说成研究 "decoy passages"，
   逐字核标题后**对象是 demonstrations 而非 decoy**。
4. **找不到就写"没找到"**，并写清搜过什么（关键词、哪些库、哪些会议）。**不许拿二手博客/内容农场当依据。**
5. **每个问题至少 2 个独立来源**；做不到就明说只有 1 个并解释。
6. 长文**一律 curl/脚本存盘**到 `raw/<组>/`，**不许手抄**（手抄实测 77 行错 2 处）。
7. **结论分三段写：依据 / 推导 / 结论**。
8. **不许改仓库任何代码或文档**（除非任务书明确要求），只读 + 在 `var/tmp/study/problems/` 下写盘。

### 2.3 已经踩过的坑（别再踩）

| 坑 | 症状 | 正确做法 |
|---|---|---|
| **Python 字符串里嵌 ASCII 双引号** | `SyntaxError`（本项目连踩多次） | 内层用中文引号「」或单引号 |
| **PowerShell 里 `<<'EOF'`** | 不支持 | 写消息到文件，用 `git commit -F file` |
| **PowerShell 双引号串里的 `` `u ``** | 被当 Unicode 转义解析 | 同样写文件 |
| **`Select-String` 命中 minified JSON** | 单行几十万字符**炸满输出** | 先 `-List`，或限定 `-NotMatch 'json'`，或先过滤文件 |
| **grep 模式太宽** | 匹配 250+ 处、输出被存到临时文件 | 收窄 `include` 与模式，先看结构再查 |
| **PowerShell `-join` 当参数用** | 报错并刷屏 | `-join` 是运算符不是参数，写法要对 |

## 4. ⚠ 已回的两组带回了**推翻性证据**——接手者必须知道，否则会重复我的错

**这三条是本轮最贵的产出，都是子代理回一手件核出来的：**

### 4.1 🔴 「抄 graphiti 的图边时间失效」——**撤回**

我此前对业主说过"要抄"，**是错的**。
`getzep/graphiti` main 源码 `graphiti_core/utils/maintenance/edge_operations.py:414` 传的是
**空过滤器** `search_filter=SearchFilters()`（隔壁 `:399` 才是 `SearchFilters(edge_uuids=...)`）
⇒ 失效候选集是该 group 内**每一条**语义相似的边，**不要求与新事实共享任何实体**。

**反证**：上游 issue **#1728**（约 3,950 条事实的生产图里 **41%** 边带 `invalid_at`，抽检 4 条 **3 条误伤**）
+ 第三方现场报告 40 例盲判 **28 例误伤 = 70%**，Wilson 95% CI **[54.6%, 81.9%]**；修复 PR #1729 自 2026-08-04 open 未审。

⇒ **只抄那三列双时态字段（`valid_at`/`invalid_at`/`expired_at`），算法不抄。**
⚠ 元教训：审计要查 `expired_at`（事务时间）**不是** `invalid_at`（会被回填）——查错列让可判定集小到 1/4。

### 4.2 🔴 「向量通道贡献≈0 ⇒ 无害」——**这一步推错了**

我们的消融只证了"**去掉它，问答指标不动**"，我把它推成了"**所以它无害**"。**两件事不是一件。**

三条独立反证，其中一条**正落在我们的语料类型上**：
- **ECHR 法律域实测：按相似度排比随机排还差**（arXiv 2606.03728 原文
  "ranking by similarity performs **worse than random selection** at surfacing gold citation paragraphs"）；
- Bekko（arXiv 2607.25180, 2026-07）实测 **BM25 打败全部 12 个稠密模型**于长文档基准；
- 强塞静态通道在留出折上**显著变差**（arXiv 2608.02112）。

⇒ **在 ECHR 那条出来之前，"默认关掉向量通道"不能当成已证无害的动作。**

### 4.3 C 组给的"我们独有的"最强候选

**全场（graphiti / Zep / PPMF / MAP-Graph）只记"失效了"，不记"谁说它失效了"。**
PPMF（arXiv 2607.29167）证明这不是洁癖：在 LLM 归并中，
**一条低信任的外部观察会被改写成"看起来像用户历史"**，抹掉限制其权威性的来源（脆弱时 ASR 高达 **1.000**）。

⇒ 派生层必须有 **`invalidation_source` + `material_review` 两列，且平台维护、模型不可改**。

### 4.4 其他可抄的（细节见两份报告）

- **TierMem**（`github.com/FreedomIntelligence/Tiermem`）§1/§2：provenance 指针 + **sufficiency router**
  （判"够不够"不是"像不像"）+ verified write-back。实测 token **−54.1%**、延迟 **−60.7%**、精度只掉 2.2 点。
- **CommitDistill**（arXiv 2605.18284, Microsoft）：git 历史当检索源，**1 万次提交抽取 < 4 秒**、θ=2.5 弃答阈值。
  ⚠ 但它同时**独立复现了"检索指标 ≠ 答案质量"** ⇒ git 历史**该当检索源，不该指望它改善答案质量**。
- **Eywa**（arXiv 2605.30771）§4.1 的写入前验证谓词 `V = V_support ∧ V_hard ∧ V_subject ∧ V_act`；
  实测拒掉 11/132（8.3%），但 **67.4% 候选无任何硬锚点** ⇒ 只覆盖三分之一。
- **Anthropic Skills 官方文档**：Level 1 **≈100 tokens/skill 常驻**、Level 2 **<5k**、Level 3 未读文件
  **"cost zero tokens"**；同厂 Tool Search 官方页逐字 **"超过 30–50 个工具，选对能力就下降"**
  ⇒ 目前唯一可机械对照的**条目数拐点**。
- **F2 是个活 bug**：`reranker.py:59-64` 返回已排序的分数，`hybrid_engine.py:466-470` 又按下标对齐再排一次
  ⇒ **恒等置换**（已机械复算：`ordered == [0,1,2,3] → True`），`debug["rerank_score"]` 还是贴错的。
  **上游 fastembed 本来就是对的**（与输入同序、绝不排序）⇒ 删掉包装层排序即可，**是恢复契约不是改契约**。
- **换长窗口模型的收益（~24%）远大于换切分策略（~4%）**；但 **late chunking 现阶段不该抄**
  （arXiv 2602.16974 实测 in-document 检索全配置变差：Jina-v3 −29.82%、Nomic −53.17%，
  而我们的用法最像 in-document）。

## 10. 一句话提醒

**这个任务最容易失败的方式，不是搜得不够多，是搜完之后写出一堆"可以参考"。**
对策表的价值在于能直接决定"抄不抄"。**落不进三栏之一的，等于没查清。**

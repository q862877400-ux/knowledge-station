## 6. 判定与报告格式

每条说法给一个判定：**PASS / FAIL / UNVERIFIED**，外加严重度（HIGH/MED/LOW）。总判定三选一：
**PASS**（说法成立、没找到洞）/ **PASS-with-gaps**（成立但有你验不到的）/ **FAIL**（找到洞）。

报告至少要有：
1. 首尾各一次 `rev-parse HEAD` + `status --short`；
2. 一句总判定 + 计数（几条 PASS / FAIL / UNVERIFIED，HIGH/MED/LOW 各几）；
3. **逐条**：说法 → 你怎么测的（**原命令**）→ **原始输出**（粘贴）→ 判定；
4. 你**没验成**的（及原因）；
5. 你**改了又还原**的清单（每条附还原后的 `status --short`）；
6. 你**顺手发现、但不属于本批**的（单列，别混进结论）。

收尾消息（≤30 行）：总判定 + HIGH/MED/LOW 计数 + 每条 HIGH/MED 一句话 + 覆盖缺口。

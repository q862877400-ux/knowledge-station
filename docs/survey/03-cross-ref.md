## 一、引用计数的口径（先看这个，否则会误读）

`text_hits` = 该符号名在扫描面内全部 `.py` 文本里出现的次数（**含定义行本身**）。

**这是下界，不是精确调用图。** 原因是 Python 有四种调用方式在看文本时不可见：
1. `getattr` / `importlib` 动态取；
2. 装饰器注册（函数名写进装饰器参数）；
3. 字符串派发（本仓 5 个渠道适配器就是 `_safe_import("mem_gov", ...)`）；
4. 框架按名字收集（pytest 收集 `test_*`）。

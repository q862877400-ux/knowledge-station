# 代码评审七条清单（含必验五种并入版）

> 批3 尾件 2/4（2026-09-22）。dsh-adopt §50.4「复核清单并 code-review 七条」的落地：
> 把本仓 62+ 轮复核实践归纳成**评审七条**，并把 AGENTS.md 的必验五种并入触发条件。
> 用法：每个实施批的自查与独立复核都照这七条走；命中必验触发 ⇒ 派独立复核。

## 评审七条（逐条问，缺一不签）

1. **判据有牙**：新增/修改的断言做过变异验证吗（改功能 ⇒ 断言必红）？有没有恒真/空过面
   （含"词在汇总行里也出现"式的假通过、"手抄少一半也过"的单向检查）？
2. **对账留痕**：改了判据/清单/冻结表 ⇒ 对账写清（改几条/为什么/旧口径原文留痕）？
   涉及台账数字（删增计数）机械数过没有（不凭印象）？
3. **诚实边界**：宣称"已验"的东西真的验了吗（真渲染 ≠ 静态渲染；机制半 ≠ 可见半）？
   未验的写"明确未做"了吗？前提有二手转述吗（回原始来源核：`git ls-files` / 实测 / 真文件存在性）？
4. **红线**：红色定位箭头（禁 bbox 框）／产出物只 Markdown／评审硬门（人工上传免评审、自采才评，
   安全面只紧不松）／采集每次先问／否决不重提（NOT-DOING 台账）——有破吗？
5. **单一出处 / 防漂移**：新常量/表格/清单有没有造第二份（跨语言同源的有同步判据吗）？
   生成物有没有手编（生成式目录/技能正文类）？
6. **P2 写作规范**：真 token 无字面兜底（含 `var(...,#hex)`）／官方件优先不自绘（Toast/Button/
   Checkbox/Tag…）／用户可见文字无字面 `**`／四个状态词与一套动词表（ui-language-spec）。
7. **文档预算 + 可回退**：一文件一主题、详细记录进归属文档别处只链接、长文搬运脚本化（禁手抄）；
   改动是小提交+可回退吗（消息=改了什么/为什么/边界，消息写文件用 -F）？

## 必验五种（命中 ⇒ 派独立复核；AGENTS.md 原文为准）

① 新增或修改"判据/门禁/棘轮/护栏"的批次（22/23 抓真缺陷）；② 触碰真数据或不可逆写入（6/6）；
③ 结论由作者自己的检查得出（5/5）；④ 面向上线的契约/schema；⑤ 作者当天刚写的新判据（最脆）。
不必验：纯文档编号措辞／同病根第 3 轮起／上轮已逐条重做验证过的同批变异。
派发协议：冻结 tag + `rev-list --count` 数提交、提取树上验（真拷贝 node_modules×2 + .venv）、
变异单侧纪律（fixture 与判据同词 replace = 自我印证无效）、还原用 `git status --short` 判。
⚠ **测试必须以提取树为 CWD 跑**（复核 verify-freeze-yi 补，2026-09-22）：venv 无 editable
安装，`src.*` 靠 `sys.path[0]=CWD` 解析——CWD 落主仓 ⇒ 变异根本不进被测代码（该轮实测
假绿 1 passed，当场识破才拿到真红）。

## 文档预算（第 7 条的量化口径）

- 一个文件一个主题；归属层唯一（做过什么→开发史；设计→INTERACTION-DESIGN；…见 AGENTS.md）。
- 引用长规则**链接**归属文档，不复制第二份（复制=漂移源）。
- 长文档搬运一律脚本化（手抄实测 77 行错 2 处）。
- 生成物（docs/tool-catalog.md 等）只由生成器写，手改必红（各自 --check 门禁）。

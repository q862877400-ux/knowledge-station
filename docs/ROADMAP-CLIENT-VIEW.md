## 〇、总目标（一句话）

> **让不专业的人用大白话、对任意资料类型提问，都能定位到「可点开的那段原文」。**

项目 2026-09-17 已转向：从「法规问答工具」变成「**通用资料研究 + 交付工具**」，法条问答退成**其中一个数据源**。

**三条别人没有的**（2026-09-25 复核，同类项目未找到等价物）：
1. **引用精确到条款**（同类最多到"文档/片段 + 来源摘要"）；
2. **机器可判定的核验**（数值/模态/法理三层，核验不过不许复制）；
3. **你自己的资料也能当依据，但必须过你的评审门**（只有你能批准）。

**三条总判据**（都可机械重跑，不接受"我觉得好多了"）：
① 大白话与原文对不上的比例**降下来**；② 有词对得上的那部分里，**前五命中率提上去**；
③ **换资料类型不塌**。

## 二、长期计划（分阶段，有明确先后依赖）

| 阶段 | 要解决的事 | 先后关系 |
|---|---|---|
| **P0 修尺子** | 让"好不好"能量得准。尺子不准，后面全是白干 | 进行中，快收口 |
| **P1 翻译层** | 把大白话换成库里会出现的说法。**它是唯一同时治"找不到"和"排不上"的一层** | P0 之后；**最高优先** |
| **P2 排序** | 词对得上也排不上来：**47% 有对得上的词，进前五的只有 4.4%** | 与 P1 **互不阻塞，都要做** |
| **P3 跨资料类型** | 换资料类型不塌（英文、古籍、技术文档）；**你自己的资料那一侧目前只有"按字找"、缺语义一路** | 依赖 P0 的尺子 |
| **P4 控制层** | 谁决定"这次找什么、找多少、什么时候停"——含**要不要把两处证据合起来**（我们缺的多跳闸）、预算、候选打分、停止条件 | 可与 P1/P2 并行 |
| **P5 多跳 + 引用质量** | 跨条款推理；量化"引用的质量" | **前置未到**：证据之间的关联密度只有 **0.026**（需要 0.3~0.5）；金标要先补"答案片段"字段；**真实提问分布要从现在起攒** |
| **通用化落地** | 材料平面（已建并可入库）→ 从"结论"走到"能交的东西"（**只出 Markdown**，依据按承重能力分组） | 与检索线并行 |

## 三、计划做完，你能得到什么（按你会感受到的顺序）

1. **用大白话问任何资料，都能翻到原文那一句。**
   *今天*：术语式 92.8% 找得到，**大白话只有 20%**——这是最大的缺口，也是 P1 存在的理由。
2. **结论敢拿去交差。** 答案固定三段（依据 / 推导 / 结论）；系统会**拿答案回原文对四件事**——引用条款号在不在证据里、数字和单位有没有被改、原文的"应"（强制）有没有被说成"宜"（推荐）、例外和但书有没有被吞掉。
3. **你自己的资料能当依据，但只有你能批准。** 没批准的**绝不会**出现在结论里；并且分清"来源多可信"和"这次能不能当依据"两条轴（公司制度可以提为本次的准则）。
4. **从结论走到能交的东西。** 出研究报告（Markdown），依据按"承重能力"分组，可疑的行标出来。
5. **库自动保鲜。** 每天扫官方渠道，发现新版/废止 → 静默下载新版、切换默认引用、旧版备份 → 告诉你**影响了哪些旧引用**。
6. **质量不会悄悄退步。** **96 条冻结问答对**写进了自动检查，指标回退超过 2 个百分点**直接判失败**；另有"只许涨不许跌"的棘轮。
7. **装起来省事。** 就在你现在用的侧栏里，**不用装数据库/队列/向量库**；数据全在本机；断网也能检索、核验、高亮。

## 四、本版**更正**的三处（都是先前说法已过期，留痕在此）

| 先前的说法 | 2026-09-25 核到的实情 | 怎么核的 |
|---|---|---|
| 材料平面"**真机上还没跑过一次**，生产库里还没有对应的表" | **已经可用**：引擎侧直接列出 **3 个参考资料项目**；最大那个项目 **38 份材料 / 7,354 个片段**，无 0 片段材料 | 通过正在运行的引擎查项目清单；再直接核每份材料的片段数 |
| 「人工维护渠道」**这条路现在是死的**（增删改接口返回 404，前缀多一个斜杠） | **已修好**：前缀常量不再带多余斜杠，而且有一条自动检查**专门钉死"不许带斜杠"** | 读源码常量 + 那条断言；该检查属今天全绿的全链冒烟 |
| 办事台里那五件「**引擎有、界面没接**」 | **其中四件已删**（合同审查、义务清单转检查表、批量问答、条款释义——你 2026-09-22 裁定"没用"）；**但"制度差距分析"没有删，它还在办事台里、可点可用** —— 先前把它和那四件混在一起说，是错的 | 核代码：审查/义务清单/批量问答三个模块已不存在；差距分析的模块与两条接口**都在**，办事台里它的状态是"可点" |

## 六、我现在**不敢保证**的（诚实边界）

1. **大白话检索仍是最大的坑**——P1 没完成；而且它下一步**被评测基准卡着**：现有测试题测不出"对真实用户会怎样"。
2. **多跳**与**引用质量量化**被前置条件挡着，**现在做必然是无源之水**（关联密度差一个数量级）。
3. **检索质量守卫还没恢复**（早前连带丢了 3 个），恢复前要先摘掉评测台的审查那半边。
4. **有一项自动检查每次跑都超时间预算**（实测 298 秒 / 预算 240 秒），**原因尚未查明**——它是告警不是失败，但没查清就不算过关。
5. **真实提问分布没有数据**：这是唯一能替代"我替外行想象"的东西，**它只能靠从现在起把提问攒下来**。
6. 界面那条线里，**"有效性筛选与四色灯同步"尚未开工**；分类关键词补准**要重启引擎才生效**（意味着今天改的，重启后才是真的）。
7. 本文的数字**都有日期**；凡是我没有在 2026-09-25 亲手核过的，都写明了它是哪一天量的。

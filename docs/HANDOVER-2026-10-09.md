## 一、一句话

**KnowledgeStation：让不懂行的人用大白话，对自己机器上的任意资料提问，直接定位到那段可点开的原文。**

形态 = **两个进程一起交付**：**Python 引擎**（`src/core/`，跑检索/入库/核验，走本地 HTTP）
+ **DSH 插件**（`plugin/`，出侧栏界面、给对话挂工具）。**没有独立 EXE。**

法规 / 国标只是其中一类数据源，**不是主体**。

## 二、项目是什么（说人话）

- 你有一个问题，用的是自己的说法（不是法条里的词）；
- 它在你机器上的资料里找出**最相关的那几段原文**，标出出处（哪一篇、哪一条）；
- 点一下，跳到那份文件的那一页；
- 答案分三段（**依据 / 推导 / 结论**），而且**过机器核验**（数字、模态词、法理三层）——
  **核验不过，不许复制**。

## 三、只有三条是别人没有的（2026-09-25 复核过）

1. 引用精确到**条款**（同类产品最多到"文档/片段"）；
2. 机器可判定的**核验**（不是靠模型自说自话）；
3. **你自己的资料也能当依据，但只有你能批准**。

## 十一、踩过的坑（**别再踩**）

| 坑 | 表现 | 正确做法 |
|---|---|---|
| **冻结哈希对行尾（EOL）敏感** | `stop-loss.json` 的哈希是 **LF**（= `git show <tag>:<path>` 的 blob）；Windows `core.autocrlf=true` 下提取树 fresh checkout 变 **CRLF** ⇒ 直接 `sha256sum` **核不上** | 一律 `git show <tag>:<path> \| sha256sum`，或统一去 CR 归一化再比。⚠ 在 `.gitattributes` 固定 `-text` 属**仓级改动，需业主点头** |
| **在 vec0 虚表上用 `NOT EXISTS` 做集合差** | >45 s 未完成（疑 O(n²)） | 取两侧 id 到 Python 集合再做对称差（1 s 级） |
| **shell 后台进程被杀** | `nohup ... &` 起的长任务，Bash 调用一结束就死 | 用 `run_in_background=true` |
| **长任务接 `tail`** | 输出被缓冲，10 分钟看不到任何东西 | 直接落日志文件再读 |
| **门禁从 bash 调 pwsh** | 被拒 | 用 PowerShell 工具 |
| **`git commit` 不带 pathspec** | 会把索引里**别人暂存**的文件卷进你的提交 | 一律 `git commit -F - -- <自己的路径…>` |
| **复核在"边改边验"里做** | 实施代理的变异周期把主仓弄脏 ⇒ 双向污染 | 复核必须在**冻结提交的提取树**上验（`git worktree add` / `git archive`） |
| **提取树里装依赖用 junction** | esbuild 把绝对路径打进产物 ⇒ "整份一致"断言**假红** | 真拷贝两份（`plugin/node_modules` + 仓库根那份） |
| **清提取树前不确认** | 把复核正在用的对照树删了 ⇒ 原始证据永久丢失 | 清之前先确认没有在跑的复核 |

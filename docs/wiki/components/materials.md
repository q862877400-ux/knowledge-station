# materials（材料平面）

**位置**：`src/core/materials/`
**一句话**：让用户自己上传/采集的资料也能当依据——但要过权威性纪律。

## 职责

**「自有材料也能当依据」这一件护城河的实现**：把可信度从**标签**变成**可执行规则**（`authority.py`）、自采入口（`collect.py`）、网页采集（`harvest.py`）、近重复检测（`dedup.py`）、定位（`locator.py`）、跟踪（`track_l.py`）。

**它不负责**：不做条款检索（`retrieval`）、不做解析（`ingestion` 的 `material_ingest.py`）、不决定评审（**用户上传的免评审**）。

## 对外提供什么

| 提供物 | 形式 | 调用方 |
|---|---|---|
| 权威性规则 | `authority.py`（T0~T4 从标签变成可执行规则） | 作答链路 |
| 自采入口 | `collect.py` | 用户 |
| 网页采集器 | `harvest.py` | 自采 |
| 近重复检测 | `dedup.py` | 入库前置 |
| 定位 | `locator.py` | 引用回原文 |
| 跟踪 | `track_l.py` | 变更跟踪 |

## 依赖什么

| 依赖 | 类型 | 用途 |
|---|---|---|
| `storage`（`material_repo`） | 上游模块 | 材料与切片的持久化 |
| `ingestion/material_ingest.py` | 同仓 | 材料解析入库 |

## 明确不做什么

- **不对用户手传材料设评审门**：业主裁定「我既然人工上传…那肯定我知道我上传的是什么」——**传完即用**，只留「必须遵守 / 仅供参考」一个小选择。
- **但自采材料（含渠道自动更新灌进来的）要人看一眼**（业主 2026-09-30「2 要看一眼」）。
- **本模块 MUST NOT 替用户做权威性判断**：它提供规则与默认档，最终由用户选。

## 已知边界（诚实）

- **材料默认低于法规**（分层权威）。
- **实测规模**：材料 81 份 / 3 个项目 / 7,872 切片。
- ⚠ 「评审门」这个词在旧文档里出现过，**已经作废为「用户手传的免评审」**——见 `docs/NOT-DOING.md` #15 与 `docs/research/vision-coverage-map.md` §三.2 的更正框。

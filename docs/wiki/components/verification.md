# verification（分型核验）

**位置**：`src/core/verification/`
**一句话**：检查答案里那些「按规定该是什么」的东西对不对。

## 职责

**核验层**：分型核验器（`typed_verifier.py` 13.6 KB，T06）——按值的**类型**（数值 / 模态 / 法理）分别校验；纠错补丁防乱检测（`patch_guard.py`，防补丁把不该改的改了）。

**它不负责**：不检索（`retrieval`）、不生成答案（`llm`）、不做质量分级（`quality`）。

## 对外提供什么

| 分型核验 | `typed_verifier.py` | `llm` 作答后、`api` 返回前 |
| 补丁防乱 | `patch_guard.py` | 纠错补丁链路 |

## 依赖什么

| `storage` | 上游模块 | 取条款原文与现行性 |
| `quality` | 同仓 | 分级判据 |

## 明确不做什么

- **不做数值的「算法口径」核验**：本模块管的是「**你写的数是不是条文里那个数**」；
  「**你用的是不是规定的方法**」是另一件事（外部标准 OKF 的 Attested Computation 管那个），**本仓没有这个需求**。
- **不修数据**：只报告不一致，改由调用方决定。
- **不做检索**：核验拿到的候选由 `retrieval` 给。

## 已知边界（诚实）

- **本模块是产品红线之一**：「AI 不许编条款号、不许混版本」的落地处。
- ⚠ **未核验不得承重**：答案还没核验完，不许让用户复制出去（本仓独有红线）。

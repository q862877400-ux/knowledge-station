# vision（本地视觉）

**位置**：`src/core/vision/`
**一句话**：在没有云端视觉 API 的情况下，也能看图回答问题。

## 职责

**本地视觉反查**（`local_vision.py` 4.8 KB）——Task 11.4 落地为本地版，**替代云端视觉 API**。

**它不负责**：不做版面解析（`ingestion` 的 MinerU 管那个）、不做 OCR 主链路。

## 对外提供什么

| 本地视觉反查 | `local_vision.py` | 入库/检索的辅助链路 |

## 依赖什么

| 本机模型（VLM） | 外部 | 推理 |

## 明确不做什么

- **不替代 MinerU 的版面解析**：那是有坐标的解析，本模块是「看图找东西」。
- **不做云端调用**：它的存在理由就是**本地**（云端视觉 API 已被它替代）。

## 已知边界（诚实）

- ⚠ **本仓有一份被否决的方案**：`docs/WSL2-VLM-BACKEND-DECISION.md` 记录了 WSL2 后端那次「否决，保留复议权」。改本模块前先读它。

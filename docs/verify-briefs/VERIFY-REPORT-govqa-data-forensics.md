**根因**（`build_lawstd_index.py` 第 36 行）：

```python
src = os.path.basename(f).replace(".jsonl", "")
```

索引写入的 `source` 是**文件名主干**，例如：
`'ah-kb-安徽省直部门·共享问答知识库'`、`'baotou-igi-15-包头市·政民互动信箱（IGI）·siteId=15'`。

而语料记录内的 `source` 字段是**适配器 key**：`'ah-kb'`、`'baotou-igi-15'`。

**⇒ 索引与语料用的是两套不同的 source 命名，`source` 无法作连接键。**
这不是「数据被改过」，而是**建索引时就写错了键**。

**索引已过期**：按 `(source,id)` 精确连接命中 **0/7,879**；
即使做前缀归一化，也只有 74.7% 命中 ⇒ **约 25% 的索引条目在当前语料中找不到对应记录**。

## 逐渠道证据

### 1. mohurd 标准公告页（GB 55037-2022《建筑防火通用规范》公告）
- 请求1 GET：200，text/html，22,856B，可见文本 12,719 字符，无 JS 壳，无登录/验证码标记。
- 请求2（编码 GBK 修复）：正文可见
  - `现批准《建筑防火通用规范》为国家标准，编号为GB 55037-2022，自2023年6月1日起实施。本规范为强制性工程建设规范，全部条文必须严格执行。现行工程建设标准中有关规定与本规范不一致的，以本规范的规定为准。同时废止下列工程建设标准相关强制性条文：`
  - `发布时间：2023-01-19 14:22:22`、`实施日期： 2023-06-01`、`附件下载` 区块
  - 附件链接（唯一）为相对路径：`/api-gateway/jpaas-web-server/front/document/download?fileUrl=YW5UzzlvCwcM%2F...`（编码文件引用，非 .pdf/.doc 直链）
- 请求3 直连该网关 URL：HTTP 200 但返回 `text/html` 空壳（`<html><head></head><body>`），无 PDF 字节 → **附件需复现网关参数（Referer/session），不能静态直连**。
- 结论：公告号/发布/实施/废止清单 全部静态可解析，时效巡检价值极高；附件抓取需 1 次带 Referer 的复测。

### 2. mohurd 文告列表页（art_004fc...）
- 请求1 GET：200，16,750B，静态，可见文本 5,252 字符；日期匹配 2024-08-08 / 2025-04-07 / 2026-04-01。
- 请求2：`<a>` 共 26 个，含 8+ 条文告条目，如
  - `住房城乡建设部 国家发展改革委关于批准发布城市公共体育场建设标准的通知（建标〔2024〕50号） -> /gongkai/zc/wjk/art/2024/art_17339_779537.html`
  - `住房城乡建设部关于发布国家标准《绿色建筑评价标准》局部修订的公告 -> ...art_17339_779172.html`
- 结论：文告库列表静态可抓，标题/文号/链接/日期齐全，可做公告级时效巡检。

### 3. gov.cn 政策库转发页（住宅项目规范公告）
- 请求1 GET：200，29,679B，静态；标题 `住房城乡建设部关于发布国家标准《住宅项目规范》的公告_国务院部门文件_中国政府网`；日期 2025-03-31（发布）。
- 附件链接（页面内 2 处相同）：`./P020250401157366903671.pdf`
- 请求2 直连：200，`application/pdf`，3,724,937B，头字节 `%PDF-1.5`，无登录跳转 → **全文 PDF 静态直连可用**。
- 结论：全文比对一级来源（但只覆盖 gov.cn 转发的公告，非全覆盖）。

### 4. ebook.chinabuilding.com.cn（国标电子书库）
- 请求1 GET 根页：200，629B 纯 JS 跳转壳：`window.location='https://ebook.chinabuilding.com.cn/zbooklib/index?SiteID=1'`。
- 请求3 GET /zbooklib/index?SiteID=1：200，342,773B（服务端渲染），可见文本 14,706 字符，含 登录/注册/账号/login 标记。
- 结论：SPA 结构，标准正文阅读为机构订阅制（登录墙），仅可做存活/元数据探测，不可做公开巡检或全文比对。

### 5. ttbz 详情页（T/ZSA 328）
- 请求1 GET：200，232,701B，纯静态；标题 `T/ZSA 328—2026 科技成果转化为标准 成熟度模型 - 团体标准`。
- 请求2 字段提取（可见文本直读）：
  - `公布日期：2026-07-01 发布日期：2026-01-29 实施日期：2026-01-30 所属团体：中关村标准化协会`
  - 状态行：`现行 T/ZSA 328—2026 ... 中关村标准化协会 发布`（status 现行直接呈现；JS 内含 `废止": "ABOLISH"` 状态映射）
  - 页面含 JSON-LD `schema.org/TechArticle`：datePublished 2026-01-29、dateModified 2026-07-01、author=中关村标准化协会 —— 结构化元数据直接可用
- 附件（1 个）：`/UploadFiles/StandardFpdFile/20260313134422484.pdf`
- 请求3 直连：200，`application/pdf` 126,702B 真 PDF → 公告 PDF 直连可用；但该附件是**标准发布公告**，非标准全文。
- 全文状态：页面数据 `"现行","isSale":1,"isSaleName":"可出售"` → 标准全文需登录/付费，**不可做公开全文比对**。
- 结论：状态/公布/发布/实施日期 全部静态可解析 → 元数据时效巡检可接入；全文比对不可。

### 6. ttbz 首页
- 请求1 GET：200，243,221B，静态，robots `index,follow`（放行）。
- 请求2：标准查询入口为 Vue 搜索框 `v-model="searchKeyword"` + `@click="doHomeSearch"`（JS 驱动，可模拟其搜索 API）；无 `<form action>` 静态表单。列表/详情页均为服务端静态页。
- 结论：巡检建议直接抓列表页/详情页（静态），搜索 API 可按需模拟。

### 7. qybz.org.cn（企业标准信息公共服务平台）
- 请求1（python requests）：SSLError `[SSL: UNEXPECTED_EOF_WHILE_READING]`。
- 请求2-4（curl.exe Schannel）：
  - `https://www.qybz.org.cn` → `code=000`，`curl: (35) schannel: failed to receive handshake`
  - `--tlsv1.2` / `-4` 同失败
  - `http://www.qybz.org.cn` → `502`
- 结论：本机网络在 TLS 层被拒（握手即断开），http 回退 502——平台对本 IP 段/网络不可达，无法纳入巡检；需在可访问网络（如国内住宅/机构 IP）复测。

## 反爬/登录汇总
- 全部可达渠道在浏览器 UA 下：无验证码、无 WAF 拦截、无频率限制提示；ttbz/gov.cn 明确 robots index,follow。
- 需登录：ebook（全文，机构订阅）、ttbz 全文在线阅读（付费/登录）。
- 网络层拒绝：qybz（TLS 握手断开）。
- 附件直连：gov.cn ✅（静态 PDF）、ttbz 公告 PDF ✅、mohurd ⚠️（网关接口，需补 Referer/参数复测）。

## 选型结论
- **可接入时效巡检（元数据+状态/日期）**：住建部公告页与文告列表页、gov.cn 转发页、ttbz 详情页与列表页 —— 4 个渠道全部静态可抓，无登录。
- **可做全文比对**：gov.cn（静态直链 PDF，首选）；ttbz 仅公告 PDF（非标准全文）；mohurd 附件需补 1 次带 Referer 的网关复测（预计可通）；ebook 全文不可（登录墙）；qybz 不可（网络不可达）。
- **建议巡检组合**：住建部文告列表+公告页（时效主源）→ ttbz 详情页（团标状态/日期，JSON-LD 可直接解析）→ gov.cn（全文 PDF 比对）+ mohurd 网关附件（复测通过后加入全文比对）。

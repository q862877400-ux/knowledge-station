## 2. 总目标与总判据

**总目标**：让**不专业的人用大白话**、对**任意资料类型**提问时，都能定位到**可点开的那段原文**。

**三条总判据**（全部可机械量、必须能重跑）：

1. **换词可对**：那 53% "一个字都对不上"的比例**降下来**（P1 的直接指标）。
2. **排得上去**：有重合的子集里，前五命中率**从 4.4% 提上去**（P2 的直接指标）。
3. **换资料类型不塌**：`scripts/measure-cross-language-fts.py` 在四类语料上重跑，指标不退化（P3 的直接指标）。

**每个阶段收口都要过两关**：`pwsh -File scripts/run-gates.ps1 -Full` 全绿，且**该阶段新写的判据能被自己证伪**（不是恒真）。

### P1 · 第 2 步「翻译层」（**最高优先**）

**要解决的事**：把用户的大白话**换成库里会出现的说法**。

**为什么是它、而且是现在**：53% 零重合 ⇒ 对这部分**任何检索路都无解**（按字、按意思都试过，6.8% vs 5.8%）；
而剩下 47% 的"钩子太弱"也靠它变强。**它是唯一同时作用于两条总判据的那一层。**

**做什么**（三层料，按可得性排）：

1. **先用手里已有的 2,000 条生成结果反推**——那 971 条"零重合"就是天然的困难样例集，不需要新生成。
2. **百科别名**（按词查，不下整库）：Wikidata aliases（**CC0**，许可最干净）、中文维基重定向（168 万条，需配 283 MB 的 page 表）、大词林（CC BY-SA，75 万实体）。
3. **库里自己的术语章节**：自动抽，**天然分领域**（满足"不能人工维护法规表"）。
4. **库内真人写的桥**（「以下简称/俗称」）：**实测料极少**（俗称仅 62 条、0.01%），只当补充，**不当主来源**；英文侧**完全不成立**（开发文档里「也叫什么」类写法一个都没有）。

**判据**：
* **主判据**：那 971 条里，**有多少条变成"与定义条款有 ≥2 字重合"**（纯机械，可重跑）；
* 副判据：端到端前五/前二十命中率的变化。

**明确不做**：
* 不把**生成式改写**当主路（实测只有 20.9% 的查询受益、**25.6% 更差**）；
* 不手写法规专用词表（业主明令要通用）；
* 不引入没有许可的语料（同义词词林**官方入口与许可都未核到**，不采用）。

**风险**：受控实验里词表桥到 **80%** 就到顶，**剩 20% 未覆盖**——所以 P1 不可能单独解决问题，**必须与 P2 并行**。

### P2 · 排序（**独立战场**）

**要解决的事**：有东西可对，但排不上去。

**证据**：47.0% 的说法与原文有重合，**只有 4.4% 进前五**（38/861）。这与词汇无关。

**做什么**：**先诊断、后改法**。按可能性排查（都不需要标签）：
通道权重（`exact=2.0` 是六路最高，会不会压过其他路）→ RRF 常数 → BM25 参数 → 片段长度差异（长条款天然吃亏？）→ 同号条款过多时的次序。
每一项都要**离线可复现**。

**判据**：在有重合的子集上，前五命中率**从 4.4% 提上去**（同一个脚本重跑）。

**明确不做**：不引入学习式排序（**没有标注数据**）；不动 reranker（模型本机没下载）；**权重调参必须先用新尺子量过**（这是本轮之前的红线，现在尺子的第一块已修好，才允许谈）。

### P3 · 跨资料类型（通用化落地）

**要解决的事**：让"换一种资料"不塌。

| 子项 | 做什么 | 判据 |
|---|---|---|
| 3.1 拉丁语系 | **在提问侧加词干前缀**（索引零改动，实测 97.9%） | 英文语料"换词后能不能匹配上"从 **0% → ≥95%**；标识符与中文不受影响 |
| 3.2 古籍/文言 | 评估切分方式（字级？领域词典？） | 中文单字占比（现 30.2%）与检索命中率 |

### P4 · B3「检索分类闸」（用 Jev 做有界判断）

**要解决的事**：**谁来控制这次要找什么、找多少、什么时候停。**

**为什么是现在**：① 它**早在范围里**（B3，"未启动"）；② 本轮所有测量都说明"再加一条检索路有用但远远不够"（+59%，天花板 11.8%/24.5%）⇒ 收益在**控制层**，不在"多接一条路"。

**做什么**（蓝本是 Jev-Mem 的题目集，**照着改**，不自己发明）：
* 路由：这条问题该开哪几路（含**「要不要把至少两处证据合起来」**那道题——**我们缺的多跳闸**）；
* 预算：每路分多少；
* 候选打分（**重排模型之外的另一条排序路**，不需要另开模型）；
* 停止：够不够 / 继续找还有没有用 / 缺什么 / 有没有矛盾。

**四条硬约束（都是我们已经踩过的）**：
1. **每个循环给硬上限**，上限是**判断次数**不是时间；
2. **确定性信息自己算**（条款号、标准号、层级、页码都别问模型）；
3. **不让模型判断直接落库**（官方明示 typed output **保证接口、不保证为真**）；
4. **不让它算数、不让它比日期**。

**判据**：① 硬上限实测生效；② 路由/停止判定与人工标注的一致性（在现有 20 条中文基线上扩样）；③ 端到端命中率变化。

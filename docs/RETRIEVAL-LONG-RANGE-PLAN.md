## 2. 总目标与总判据

**总目标**：让**不专业的人用大白话**、对**任意资料类型**提问时，都能定位到**可点开的那段原文**。

**三条总判据**（全部可机械量、必须能重跑）：

1. **换词可对**：那 53% "一个字都对不上"的比例**降下来**（P1 的直接指标）。
2. **排得上去**：有重合的子集里，前五命中率**从 4.4% 提上去**（P2 的直接指标）。
3. **换资料类型不塌**：`scripts/measure-cross-language-fts.py` 在四类语料上重跑，指标不退化（P3 的直接指标）。

**每个阶段收口都要过两关**：`pwsh -File scripts/run-gates.ps1 -Full` 全绿，且**该阶段新写的判据能被自己证伪**（不是恒真）。

### P4 · B3「检索分类闸」（用 Jev 做有界判断）

**要解决的事**：**谁来控制这次要找什么、找多少、什么时候停。**

**做什么**（蓝本是 Jev-Mem 的题目集，**照着改**，不自己发明）：
* 路由：这条问题该开哪几路（含**「要不要把至少两处证据合起来」**那道题——**我们缺的多跳闸**）；
* 预算：每路分多少；
* 候选打分（**重排模型之外的另一条排序路**，不需要另开模型）；
* 停止：够不够 / 继续找还有没有用 / 缺什么 / 有没有矛盾。

**四条硬约束（都是我们已经踩过的）**：
1. **每个循环给硬上限**，上限是**判断次数**不是时间；
2. **确定性信息自己算**（条款号、标准号、层级、页码都别问模型）；
3. **不让模型判断直接落库**（官方明示 typed output **保证接口、不保证为真**）；
4. **不让它算数、不让它比日期**。

**判据**：① 硬上限实测生效；② 路由/停止判定与人工标注的一致性（在现有 20 条中文基线上扩样）；③ 端到端命中率变化。

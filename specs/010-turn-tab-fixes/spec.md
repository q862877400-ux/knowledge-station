# Feature Specification: 「本轮」页三处修正（按业主实跑反馈）

**Feature Branch**: `010-turn-tab-fixes`

**Created**: 2026-10-12

**Status**: Draft

**Input**: 业主实跑截图后提出三条：
1. 「现行有效是**文件级别**的，所以在文件名后面展示有效状态就行了」（即：效力徽章不该挂在**每条条款**上，应挂在**文件标题**上）。
2. 「这个页面**没法翻页**」。
3. 「红色箭头**还是没有**」。

## 背景：三条各自的性质（**三条完全不同**）

### 问题 1：效力徽章挂错层级（**我的实现问题**）

**现状**（业主截图可见）：每个条款行都带一枚「现行有效」徽章。
**业主的判断**：效力是**文件级**属性，应挂在**文件名后面**一次。

**核实（真库）**：`legal_status` 存在 `doc_meta` 表（文件级），**不在** `clause_revision`（条款级）。
⇒ **业主是对的，而且与数据结构一致** —— 我把文件级字段画到了条款级上。

⚠ **上一批（spec 009）我只删了 `legal_hierarchy`（那个 `GB`），没动 `legal_status`（「现行有效」）** ——
两条是**不同字段**，我上一批读业主的话时把注意力只放在了 `GB` 上。**这是我的漏读。**

### 问题 2：页面没法翻页（**我的实现问题**）

**核实**：`KsTurnTab` 的根容器是
`<div style={{ padding: '12px 14px', display: 'flex', flexDirection: 'column', gap: 8 }}>`
—— **没有任何 `overflow` 设置** ⇒ 内容超过面板高度时被裁掉，滚不动。

**对照**：同插件其它面板都在内层做滚动（`KsMaterialsPanel` 有 3 处 `overflow: 'auto'` +
`maxHeight`）；知识库页的 `.ks-kb-tree` 也有 `overflow:auto`。
⇒ **本页漏了这一条**，属实现缺陷。

### 问题 3：红箭头还是没有（**上游数据缺陷，不是我的代码**）

**这次我拿到了铁证**（全部真机 + 真库实测）：

| 环节 | 实测 | 判定 |
|---|---|---|
| `/ks/bbox` 代理 | 返回 `found:true`、真实坐标 | ✅ 通 |
| 「本轮」evidence | **没有 `bbox` 字段** | ⚠ 见下 |
| 引擎进程 | **12:27 启动**，而我的 `attach_bboxes` 改动是 **14:53** | ⚠ **引擎跑的是旧代码** |
| `/ks/bbox` 对业主那 6 条 | 返回的 bbox 是 `[0.1, 784.33, 0.88, 784.4]` = **宽 0.79pt × 高 0.07pt** | ❌ **退化框** |
| 业主那篇 `GB 17681-2024` | **370/370 条条款的 span 全是退化框（100%）** | ❌ **该文档的坐标整体不可用** |
| 页面几何对照 | 该文档页面 `554.4 × 784.8`；退化框 `x≈0.1, y≈784` ⇒ 贴着**左上角边缘** | ❌ 坐标没指向正文 |
| 对照文档 `GB/T 26718-2024` | span 正常（`261×12pt`） | ✅ |

⇒ **两个叠加原因**：
1. **引擎没重启**（我的 `attach_bboxes` 从未执行）；
2. **即使执行了**，`GB 17681-2024` 这篇的 span 全是 **0.01–0.09pt 的碎片**
   ⇒ 箭头会画成**一个看不见的点**（等于骗用户"标好了"）。

⚠ **这不是"再调一次取数逻辑"能解决的** —— 那篇 PDF 的解析产物里**没有可用的正文坐标**。

## 用户场景与验收

### US1（P1）：效力徽章挂到文件标题上

- **AC-1.1** 「现行有效」徽章出现在**文件标题行**（`GB 17681-2024` 那一行），**只出现一次**。
- **AC-1.2** **条款行不再有**效力徽章。
- **AC-1.3** 判据：渲染级断言——标题行含徽章文本；条款行不含。
- **AC-1.4** 判据有牙：把徽章搬回条款行 ⇒ 必红。

⚠ **一个文件内效力不一致怎么办**：`legal_status` 是文件级的（`doc_meta`），
同一 `doc_id` 的条款**理论上共享同一状态**。但引擎是**逐条款**给 `legal_status` 的
⇒ 若同一文件内出现两种状态（数据异常），**取第一条并如实说明**（见 AC-1.5）。

- **AC-1.5** 同文件内状态不一致时：标题行显示**第一条的状态**，且**不静默**——
  在该组下给一行小字说明（否则用户以为全组都是那个状态）。

### US2（P0）：页面必须能滚动

- **AC-2.1** 内容超出面板高度时**可以滚动**（能看到最后一条依据）。
- **AC-2.2** 判据：渲染级断言根容器**有 `overflow` 设置**（不是 `visible`）；
  且真浏览器量"内容高 > 容器高时，容器可滚"（`scrollHeight > clientHeight`）。
- **AC-2.3** 判据有牙：把 `overflow` 去掉 ⇒ 必红。

### US3（P0）：红箭头——**如实降级，不许画假箭头**

**这一条的正确目标不是"让箭头出现"，而是"别骗用户"**：

- **AC-3.1** 引擎侧：`attach_bboxes` **拒收退化框**（宽 < 5pt 或高 < 3pt）
  —— 与其画一个看不见的点，不如**不画**并让前端如实提示。
- **AC-3.2** 前端侧：取不到可用坐标时，**给出可见提示**（既有 `setAnchorWarn` 就是干这个的），
  文案要说清"**跳页仍然有效，只是定位不到那一行**"。
- **AC-3.3** 判据：① 引擎单测——退化框被拒（不写进 `bbox`）；② 前端——退化 bbox 不产生箭头位置。
- **AC-3.4** 判据有牙：把退化判定去掉 ⇒ 必红。
- ⚠ **诚实边界**：`GB 17681-2024` 那篇**坐标整体不可用**是**上游解析产物**的问题，
  本批**不改数据**（改它要重解析整篇 PDF，属要业主点头的类）。
  ⇒ **本批交付的是"如实告诉用户"，不是"让那篇能画箭头"。**

## 范围与边界

**做**：
- 效力徽章上移到文件标题（+ 组内不一致时如实说明）。
- 页面滚动。
- 退化 bbox 的拒收与如实降级提示。

**不做**：
- **不重解析 `GB 17681-2024`**（上游数据；重解析要动生产库/跑 OCR，属要业主点头的类）。
- **不重启引擎**（业主的进程；属外部动作 —— 但**要在交接里写清"必须重启引擎才生效"**）。
- **不碰**并行线写入面（`tools/gov-qa/**`、`scripts/run-gates.ps1`、`specs/004`、`specs/006`、公告组件）。

## 依赖与风险

| 风险 | 对策 |
|---|---|
| 改徽章层级会动既有渲染断言 | 逐条核 `smoke-turn-tab.mjs`，按新行为更新并**说明为什么** |
| 滚动判据在 jsdom 里量不了（无布局引擎） | 用真浏览器（`ui-render-shot`）量 `scrollHeight > clientHeight` |
| 退化阈值（5pt/3pt）是我拍的 | **写明依据**：正常正文行高 ≈ 12–13pt（实测中位 13pt）；阈值取"明显小于一行" |
| 引擎不重启 ⇒ 我的改动不生效 | **在交接单与回复里显著写明**；这是本轮必须让业主知道的一条 |

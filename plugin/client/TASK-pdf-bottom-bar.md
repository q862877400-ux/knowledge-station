## 3. 实现要点与约束

- **不要把"翻页模式"与"缩放来源"混成一个状态。** `pdfFit.ts` 的现有规则是
  「铺满 + 溢出预算」：`scale = max(fitWidth, min(fitHeight, fitWidth × 1.25))`
  （详见该文件头注释，含窄侧栏 25% 溢出的理由）。**改默认模式时不要顺带破坏这套规则。**
  建议：`mode ∈ {single, continuous}` 与 `zoomSource ∈ {autoFit, manual(percent)}` **两个独立状态**。
- 「自适应窗口」的语义按用户原话是**按窗口宽度**；而 `pdfFit.ts` 的自适应含高度参与
  （侧栏够宽时按高度拉满）。**两者不完全等价**——实现时请沿用 `pdfFit.ts` 的既有语义
  （它就是当前默认态的行为），只把"是否启用自适应"这件事做成开关，不要另造一套 fit 算法。
- 缩放滑块与下拉**共用同一百分比状态**，双向同步（拖滑块要更新下拉显示，选下拉要移动滑块）。
- 手动值需要**钳制**：最小值、最大值按 §5 确认结果。

## 一、三条主诉（**都成立**）

### 主诉 1（verifier-design，最严重）：「每次只改一处」是**假的**，机理叙事与自家产物矛盾
- **①归因硬伤**：`A→D` 与 `B→C` **都同时改了两件事**——算子（`Σ`→`max`）**和分母**（`k+r+1`→`k+r`）。
  ⇒ **「每次只改一处，保证可归因」对这两对不成立。**
- **②机理叙事与产物矛盾**：我在 `VERDICT` §四 写「**真正参与融合的只有 fts 与 vec，两路权重都是 1.0**」，
  而自家 `channel-stats.json` 写着 **`modality`（权重 0.8）在 5 条 query 上真实触发、平均灌 39,113 条**。
  ⇒ **这段解释对那 5 条不成立**；而且 `channel-stats.py` 的 docstring 自己写明这次检查就是为了
  排除「加权两路没触发」的平凡原因——**`exact` 排除了、`modality` 没排除，我的叙事没相应收窄。**
- **③「同序」是断言不是测量**：`run.py` 只记 @8/@20 命中布尔与 gold rank，
  **没有逐 query 序差 / 重叠数** ⇒ 「@20 四臂相同」推不出「序相同」。
- **④翻转来源不可追**：per_query 只在内存、没落盘 ⇒ **那 1 条翻转是谁、在哪个通道、什么池子，全部不可考。**

### 主诉 2（verifier-stats，最严重）：**条目级证据未落盘 + 结论表述过度**
- **①条目级证据未落盘**：`result.json` 只存聚合数 ⇒ 全部统计证据（"120 对中 1 对翻转"）
  **其身份不可考**；库是活库、重跑不复现。**补录成本近零，损失永久。**
- **②结论表述过度**：证据只支持「**未能检出差异**」，不支持「**没有差异**」。
  超出证据的原话有三处（标题、§四 line 93、§八 line 143）。
  **并给出了数学反例**：两路等权时 `X=(fts 0, vec 19)`、`Y=(fts 1, vec 1)` ——
  **sum 下 Y 胜、max 下 X 胜** ⇒ 「几乎必然同序」**不是定理**。
- **③§四「生产真实情况就是 exact 不触发、池子 40 条」是把考卷画像断言成生产实况**——
  120 条来自 `benchmark-v2.jsonl` 考卷，**不是生产查询日志**。**这条批评最准。**
- **④预注册写「1.96×SE = 显著」，而实现给的是 percentile CI，全文没有 SE 计算**，
  且 `VERDICT` §三「与预注册逐条对齐」表**恰好没有"统计"这一行**。

## 二、我改了什么

### 2.1 补齐归因臂（`run.py` 的 `fuse()`）
新增两臂，使「纯算子」与「纯分母」各有干净对照：

| 臂 | 公式 | 相对谁干净 |
|---|---|---|
| A | `Σ w/(k+r+1)` | 生产现状 |
| B | `Σ 1/(k+r+1)` | A 只去权重 |
| **Ap（新）** | `Σ w/(k+r)` | **A 只改分母 ±1** |
| C | `max 1/(k+r)` | B 只换算子（无权、0-based）|
| **Dp（新）** | `max w/(k+r+1)` | **A 只换算子**（权与分母都同 A）← ★ 最干净的那一对 |
| D | `max w/(k+r)` | Ap 只换算子 |

### 2.2 落盘条目级明细（两位 verifier 都要求）
- 新增 `per-query.jsonl`：**每条 query** 记 `modality_filter`、**各通道候选数**、
  **gold 在各通道内的名次**、**融合池大小**、**fts/vec 重叠数**、六臂 `@5/@8/@20/@100` 与 `rank`；
- `result.json` 新增 `per_query` 与 **`flips`（翻转明细）**。

### 2.3 ★ 追出那条翻转（这是本轮最重要的新事实）

```
{"i": 130, "gold_std": "GB/T 16845-2017", "modality_filter": null,
 "ch_n": {"exact": 0, "fts": 20, "vec": 20, "modality": 0},
 "gold_rank_in_ch": {"exact": null, "fts": 5, "vec": null, "modality": null},
 "pool": 38, "overlap": 2, "A_rank": 9, "C_rank": 8, "Dp_rank": 8, "D_rank": 8}
```

**⇒ 三条决定性事实：**
1. **翻转那条 `modality` 候选 = 0、`exact` = 0** ⇒ **三个权重（exact 2.0 / modality 0.8）一个都没参与**；
2. **只有权重都是 1.0 的 fts + vec，池子只有 38 条、重叠 2 条**；
3. **而 sum 与 max 仍然给出了不同的序**（A 给 gold 第 9，max 三臂都给第 8）。

**⇒ ⇒ 这直接证伪了我 §四 的机理叙事，而且比 verifier 说的更彻底：**
· verifier-design 写「若翻在纯 fts+vec 上 ⇒ **直接反例打脸「同序」**」——**实情正是这个**；
· **我那句「池子中位 40 ⇒ sum 与 max 几乎必然同序」是错的，本次数据里就有反例。**

## 三、更正后的数字（六臂，口径复核仍 **120/120 = 100%**）

| 臂 | 公式 | `@8` | `@20` |
|---|---|---|---|
| **A**（生产现状） | `Σ w/(k+r+1)` | 5.83 | 8.33 |
| **B** | `Σ 1/(k+r+1)` | 5.83 | 8.33 |
| **Ap**（新，只改分母） | `Σ w/(k+r)` | **5.83** | 8.33 |
| **C**（RefWalk 原样） | `max 1/(k+r)` | 6.67 | 8.33 |
| **Dp**（新，**纯算子**） | `max w/(k+r+1)` | **6.67** | 8.33 |
| **D** | `max w/(k+r)` | 6.67 | 8.33 |

**相对 A：**

| 对比 | Δ | b / c | 精确 McNemar p | cluster bootstrap 95% CI |
|---|---|---|---|---|
| **Ap（纯分母 ±1）** | **0.00** | 0 / 0 | 1.0000 | [0, 0] |
| B（纯权重） | 0.00 | 0 / 0 | 1.0000 | [0, 0] |
| **Dp（纯算子）** | **+0.83pt** | **1 / 0** | 1.0000 | [+0.00, +2.65] |
| C / D | +0.83pt | 1 / 0 | 1.0000 | [+0.00, +2.65] |

**⇒ 归因现在是干净的：**
· **纯分母偏移（A↔Ap）= 0.00** ⇒ **分母 ±1 在本数据上零影响**；
· **纯算子（A↔Dp）= +0.83pt** ⇒ **那 1 条翻转完全由「算子」造成，与分母、权重都无关**。

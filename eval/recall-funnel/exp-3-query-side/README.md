# E3：查询侧（术语桥）—— 能否**不重建向量**就把 Top1000 外的失败拉回来

> **设计冻结在跑之前。** 止损线见同目录 `stop-loss.json`（先落盘，后跑）。
> 归属：检索长周期计划 **P1「翻译层」（最高优先）**。总纲 `docs/RETRIEVAL-LONG-RANGE-PLAN.md`。

---

## 一、要回答的问题（外部评估的原话）

> **在不重建 52 万条 embedding 的前提下，仅靠查询侧把"大白话"转换成标准检索语言，
> 能不能把那 60% 的 Top1000 外失败样本明显拉回来？**

**为什么先问这个**：外部评估看到本仓台账第 21 条的旧测（重建索引 94.9% vs 只改提问 96.3%，p=0.50；
标识符存活率掉到 61.6%）后，**撤回了"换 embedding 排第一"**，改成 query-side 优先。
所以这一步是**换模型的前置闸门**：它不成立，才谈得上动 52 万条向量。

## 三、唯一变量（其余逐项冻结）

| | 内容 |
|---|---|
| **对照臂 A** | 生产现役查询串（一字不改）喂进**不改动的**生产检索链（六路 + RRF） |
| **实验臂 T** | **只换查询串**：`原查询` + 术语桥 `TermIndex.select(query, k=5)` 选出的 5 个术语名 |

**逐项冻结**：索引不动（真库只读）、六路不动、RRF 权重不动、取回数不动、模型不动、
gold 不动、171 条考卷不动、向量不动。

**一次只改一处** = **只改"送进检索的那串字"**。这与 E1（只改"送进 embedding 的条文文本"）是对称的设计。

## 四、防作弊判据（**外部评估点名的风险**）

外部警告：查询改写**不能引入 gold 条文里才有的词**，否则是作弊。

**结构性保证**：`TermIndex.select(query, k)` 的输入**只有 query**，签名里**没有 gold**；
术语索引由**全库术语条款**离线构建（`extract_term_entries` 扫全库），**不来自考卷**。
⇒ 改写**在构造上不可能**看到 gold。

**另加机械检查**（跑完必做，写进产物）：
1. 对每条题，记录**注入了哪些词**；
2. 统计这些词在**gold 条文**里的出现率 vs 在**全库**里的出现率 ——
   若注入词在 gold 里的集中度显著高于全库，说明存在间接泄漏，**该结论作废**。

## 五、验收与止损线

**主终点：六路同预算并集 @1000（全量 171 条口径）** —— 因为要回答的就是"Top1000 外的失败能不能拉回来"。

副终点：Vector@20/@100/@1000、FTS@1000、单独"原本 104 条 not-any 里救回几条"。

**阈值按我们的实测分辨力定**（不是拍脑袋，见 `exp-1-contextual/cluster-significance.json` 与 `power-factcheck.json`）：
全量 171 条口径的簇级 SE ≈ **3.31pt** ⇒ 显著性阈值 **≈6.5pt**，80% 把握度 MDE **≈9.3pt**。

| 档 | 条件 | 含义 |
|---|---|---|
| **推广** | 净提升 **≥ +9pt** 且 翻进 **≥ 3×** 翻出 | 够 80% 把握度的量级 |
| **观察** | 净提升 **+6 ~ +9pt** | 刚过显著线、不到 80% 把握度 ⇒ 单次分不出来 |
| **放弃** | 净提升 **< +6pt** | 在噪声内 ⇒ **query-side 这条闸门不通过，才轮到换模型** |

**硬失败条件**（任一命中 ⇒ 整次作废，不许解释数字）：
1. 两臂候选集合双向差集 ≠ 0；
2. 注入词在 gold 里的集中度显著高于全库（作弊）；
3. 术语索引与考卷有交集（考卷里的条文混进了术语索引）—— 需机械核。

## 六、明确不做

- 不重建任何向量、不改索引（真库只读）；
- 不换模型（那是第 2 项，且必须在本项**不通过**之后）；
- 不调 RRF、不改取回数、不接 E/F、不上 ANN；
- **不重复已测无效的两条**：先选文档再选术语、bge 官方指令前缀；
- 不用 `alias_store`（仅 32 行，不足以承载结论）；
- 不用 Gemini 做查询扩展（造题就是 Gemini，反向过程同族会高估收益）—— 外部指定 Qwen3-14B；
  但**第一轮先用现成的术语桥**（零新增依赖、已有实测支撑），Qwen3-14B 留作第二刀。

---

## 七、这一步回答不了什么（防过度解读）

- 它**只回答"查询侧单独能走多远"**，不回答"查询侧 + 换模型能走多远"；
- 它不改善考卷本身的缺陷（gold 未经人工确认、R1 档缺席）；
- 术语桥的全库选择精度只有 **top-5 8.6%** ⇒ **先验上收益上限就不高**；
  若结果是"放弃"，那是**在已知的低上限下放弃**，不能读成"查询侧这条路彻底没用"。

## 一、为什么要清洗

已知、可复算的事实：

| 事实 | 出处 |
|---|---|
| 171 条考卷里 **132 条（77.19%）** 的问法与 gold **零共同词**（与通道 B 同款分词、比对 gold 的 FTS 词集合，coverage 中位 0） | `eval/recall-funnel/lexical-overlap.json` |
| 独立标签审计（2026-09-25，分层抽 32 条）错率**按档单调上升**：nameHit **0%** / defHitOnly **0%** / **zeroOverlap 35.7%** | 计划 §3「未试清单」下方 |
| 主结果 120 里的要求类 22 条，`overlap` **全部为 1–3**（即全在 zeroOverlap 档） | 本仓实测 |
| 已抓到 2 条**解析残留金标**：第 166/167 条的条文原文以 `第二十条 标题：` 开头，不是实质条文 | 本仓实测 |
| 主结果 120 条落在 **64 条独立条文 / 58 篇文档**上（1.88 条问法/条文） | 本仓实测 |

⇒ 结论：**"没找到 gold"有一部分不是检索的锅**，是金标本身或考题本身的问题。
清洗的目的：把"金标存疑"的条目**分层标出来**，使后续统计能按层汇报，而不是混成一个数。

## 二、要求类三档（外部裁定：**按条文语义复杂度**，不看长度/overlap/能否定位）

> ⚠ **不许用长度、overlap、"能否从问法定位"分档** —— 后两者是**结果变量**，用它们定义题目难度会**数据泄漏**。
> **只看 gold 条文本身，不看 query、不看检索结果。**

**分档优先级：R3 > R2 > R1**（同时符合多条 ⇒ 归**最高**那档）。

### R1 · 原子要求
一条完整、单一的规范命题：**一个主体 + 一个行为 + 一个模态 + 一个对象/结果**。
没有复杂条件、例外、递进或程序链。
> 例：「产品应保存于清洁、干燥的环境中。」

### R2 · 条件/复合要求
存在以下**任一**情况：
- 明确前置条件；
- 两个及以上约束组合；
- 比较值、阈值、范围；
- 一个句子中有多个并列行为/对象；
- 「在……情况下，应……」这类条件结构。

### R3 · 复杂规范关系
存在以下**任一**项：
- 例外 / 豁免；
- 否定 + 例外；
- 重试 / 复检 / 再判定；
- 顺序性程序；
- 跨条款、跨表格引用；
- 多主体、多阶段、多动作；
- 「满足 A 后再 B，否则 C」之类结构。

## 三、适用范围（**我定的口径，留痕说明理由**）

- R1/R2/R3 是**规范命题**（要求）的复杂度分档。
- **只对 `kind == "要求"` 的 gold 条文分档**（171 条里 35 条；主结果 120 里 22 条）。
- `kind == "定义"` 的条文**不分这三档**（术语定义不是规范命题，硬套会造出假分层）——
  它们照旧用 `kind` 这一维统计。
- **理由**：外部评估的裁定原文是"要求类三档"。若把定义类也强分，会得到一层"看起来有分层、
  实际是我硬安的"，比不分更坏。
- ⚠ 这是**我的解释**，不是外部原话；若外部另行裁定，就地更正并留痕。

## 四、金标存疑标记（沿用 v2，不新增判据）

沿用 `build-v2.py` 已经算好的机械标记，**不再新造**：

| 标记 | 含义 | 是否移出主结果 |
|---|---|---|
| `gold_multi_def` | 同一条定义术语在**别的文档**里也出现 ⇒ 正确答案可能不止一条 | **是**（"没找到 gold" ≠ "没答对"） |
| `gold_dup_text` | 条文字节级重复（`content_hash` 相同）⇒ 同上 | **是** |
| `has_subclauses` | gold 是分节标题（下面还有子条款）⇒ 一个问法可能要跨子条款 | 否（**备注**） |

## 五、失败题四桶（外部裁定；**50 条，盲模型初分 → 人二审**）

对**对照臂失败的题**抽 50 条，分四桶（**每桶只按条文与问法本身判，不看检索分**）：

| 桶 | 判据 |
|---|---|
| **A 词汇鸿沟** | 问法的大白话与条文用词没有对应关系，但条文本身**确实**是正确答案 ⇒ 该改查询侧或表示层 |
| **B 条款本身无信息** | 条文是标题、目录、空壳、`标题：` 之类解析残留 ⇒ 换谁检索都找不到 |
| **C 标准没找对** | 问法指向的资料与 gold 所属标准**不是同一件事**（造题时选错了标准） |
| **D 金标问题** | gold 不是这条问法的正确答案（含"另有更贴切的条款"） |

**分桶优先级：B > D > C > A**（解析残留与金标错误优先于检索问题）。
规则冻结后**只许按规则判**；二审（人）**不得回头改规则**，只能改**个案标签**。

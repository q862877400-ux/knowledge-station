## 一、为什么是它

E4 第一轮 README §八 自己列了四条没回答的；E4b 做掉了第 1 条（成本/延迟）并顺带做掉了
第一轮留作"第二刀"的查询侧指令前缀。剩下三条里：

| 剩余候选 | 状态 |
|---|---|
| **1024 维（同模型升维）** | ✅ **本轮做** —— 外部要求"把换模型与升维两个变量拆开"（第一轮**固定 512 维**就是为这个） |
| BGE-M3 | ⬜ 未做（要另下模型） |
| 在清洗后的金标上重跑 | ⬜ 未做（金标未换 ⇒ 要等金标线） |

**它要回答的就一句话**：同一个模型，把输出从"截断到 512 维"改成"用满原生 1024 维"，
向量那一路会不会明显变好？**代价是向量体积翻倍（存储与扫描时间约 2×）**，所以必须连代价一起量。

## 二、唯一变量 = **输出维度**（其余逐项冻结）

| | 内容 |
|---|---|
| **对照臂 `d512`** | `Qwen3-Embedding-0.6B` 输出**取前 512 维** + L2 归一化（MRL）→ `clause_vec_qwen`（E4 第一轮算的表） |
| **实验臂 `d1024`** | `Qwen3-Embedding-0.6B` 输出**原生 1024 维** + L2 归一化 → `clause_vec_qwen1024`（本轮算的表） |

**逐项冻结**（见 `stop-loss.json` 的 `frozen_inventory`）：
- **嵌入模型不动**（同一个 Qwen3-0.6B —— 这是"换模型 vs 升维"两变量拆开后的第二刀）；
- **条文文本一字不动**（现役公式 `title + "\n" + content_text[:512]`）；
- **两臂都不加查询指令前缀**（与第一轮一致；指令前缀是 `exp-4b` 的变量，不许混进来）；
- 检索算法、六路、RRF、取回数、gold、171 条考卷 —— 全部不动；
- **语料冻结在 `exp-4` 的副本 `exp.db`（521,978 条有正文的条文）** —— 与第一轮/第二轮同一份语料，
  这样"维度"才是唯一变量（真库现已是 663,634 条，那是另一个规模，不混）。

## 三、shadow 结构（与第一轮同法，硬边界不变）

```text
exp-4/exp.db（副本，真库全程只读 mode=ro）
├── clause_vec              ← 生产 bge-small 512 维（第一轮已对齐到 521,978）
```

## 五、验收

**主终点**：**Vector @1000（主结果 120 条口径）** —— 与 E4 第一轮 / E4b 同口径，便于横向比较。
**副终点**：Vector@20 / @100；全量 171 口径；六路同预算并集 @1000；FTS @1000（**仪器对照**）。
**代价**：同一 521,978 行语料上，两臂 KNN @1000 的实测 p50/p90。

**必须两侧都报**：若 1024 维**更差**，那就是"更差"的结论，不许只报好的一侧。

### 止损线（`stop-loss.json`，跑前写死）

| 观察到的 @1000 增幅（1024 − 512） | 决策 |
|---|---|
| **< 4pt** | **放弃升维**（低于半条分辨率线，不值得 2× 向量体积与扫描时间） |
| **4 ~ 8pt** | **灰区**，记录不推进 |
| **≥ 8pt 且簇级 CI 下界 > 0** | **升维有可分辨收益** ⇒ 进生产评估 |

⚠ 8pt 是**分辨率线**（本仓实测显著性阈值 8.18pt），**不是生产切换线**；
≥10pt 仍低于 80% 把握度 MDE（11.68pt）。

## 六、仪器对照（硬性，任一非 0 先查仪器）

1. `d512` 臂必须**逐条**复现 E4 第一轮 `ctx` 臂的 `rank@1000`（`0/171 不一致`）；
2. `FTS @1000` 两臂必须**完全相同**（升维与按字找无关）；
3. 两张向量表的 `clause_revision_id` 集合**双向 EXCEPT = 0**。

## 七、★★ 结果（2026-10-09 跑完）—— **判决：放弃升维**

### 前置与仪器对照**全过**

| 检查 | 结果 |
|---|---|
| 两张向量表尺寸 | `clause_vec_qwen` 521,978 / `clause_vec_qwen1024` 521,978 ✅ |
| 双向 EXCEPT | 仅 512 = **0** / 仅 1024 = **0** ✅ |
| `d512` 臂逐条复现第一轮 `ctx` 臂 `rank@1000` | **0/171 不一致** ✅ |
| **FTS@1000 仪器对照** | 两臂**完全相同**（0 处差异），Δ 恒 `+0.00pt` ✅ |
| 真库 | 未动（全程 `mode=ro`）✅ |

### 主终点（冻结口径：Vector@1000，主结果 120 条）

| 量 | 值 |
|---|---|
| 512 维 → 1024 维 | 0.6833 → **0.7000** |
| 净提升 | **+1.67pt** |
| 簇级 95% CI | **[-5.08, +8.55]** |
| 簇级 p | **0.7284** |
| 翻进 / 翻出 | 8 / 6 |
| **判决** | **放弃升维**（+1.67pt **低于半条分辨率线 4pt**，CI 跨 0） |

### 全部终点（**涨跌两侧都报**：方向不一致）

| 终点 | all_171 | headline_120 |
|---|---|---|
| 向量 @20 | 0.2105 → 0.2047（**−0.58pt**） | 0.2417 → 0.2333（**−0.84pt**） |
| 向量 @100 | 0.3450 → 0.3392（**−0.58pt**） | 0.3583 → 0.3500（**−0.83pt**） |
| **向量 @1000** | 0.6667 → **0.6667**（**+0.00pt**） | 0.6833 → **0.7000**（**+1.67pt**） |
| 六路并集 @1000 | 0.6784 → 0.6784（+0.00pt） | 0.6917 → 0.7083（+1.66pt） |
| 生产上限口径 | 0.2281 → 0.2164（**−1.17pt**） | 0.2583 → 0.2417（**−1.66pt**） |
| **按字找 @1000（仪器对照）** | 0.1345 → 0.1345（**+0.00pt**） | 0.1417 → 0.1417（**+0.00pt**） |

⇒ **不是"普遍变好"**：@1000 微升（且只在 120 条口径上）、**@20 / @100 / 生产上限口径全部微降**
⇒ 这个 +1.67pt 更像**噪声**，不是方向性的收益。

### 代价侧（同一 521,978 行语料，KNN @1000 实测）

| 臂 | p50 | p90 | 均值 |
|---|---|---|---|
| `d512` | **787.2 ms** | 820.2 | 815.6 |
| `d1024` | **1296.4 ms** | 1348.5 | 1325.8 |
| **倍数** | **1.647×**（+509 ms/次） | 1.644× | 1.626× |

### 这说明了什么

1. **"升维"不是向量路的下一个杠杆** —— 同一个模型把 512 维用满到 1024 维，主终点只动 **+1.67pt**
   （CI [-5.08, +8.55]、p=0.73），而代价是扫描时间 **×1.65**。
2. **真正的杠杆是"换模型"与"查询指令前缀"** —— 第一轮换模型 **+32.50pt**、第二轮加指令前缀 **+15.84pt**；
   升维的 +1.67pt 约为换模型效应的 **5%**，且不显著。
3. **三个数不许相加**：第一轮（换模型，两臂都无前缀）、第二轮（同模型 512 维加前缀）、
   本轮（同模型无前缀升维）不是同一条链上的独立增益。
4. **一条可复用的判断**：当"把同一个表示用得更多"与"换一个更好的表示"同时可选时，
   本仓这三次实测一致指向**后者**。

### ⚠ 诚实边界（这一步回答不了什么）

- **语料冻结在 `exp-4` 副本的 521,978 条**（不是真库当前 663,634 条）—— 这是**刻意**的：
  为了与第一轮/第二轮同一份语料、让"维度"成为唯一变量；绝对值不代表当前生产规模。
- **未换模型**（BGE-M3 未做）；**未加查询指令前缀**（那是 `exp-4b` 的变量）。
- **未在法规语料上量副作用；未接生产链**。
- 考卷本身的缺陷（gold 未经人工确认）不会因为升维而消失。

### ⚠ 本轮自己写的一处缺陷（已修 + 已登记）

`22-cluster-ci.py` 的 `p_two_sided = 2*min(le0, ge0)` 在观测 Δ≈0 时会 **>1**（本轮首次跑出 **1.079**）
⇒ 已改成 `min(1.0, …)`。**同一公式在 `exp-4b/13-cluster-ci.py` 里也有**（那次 Δ 远离 0 ⇒ p=0.0000，
没暴露）—— 那是**已冻结/已复核**的文件，**本轮不改它**，只在此登记。
⇒ 可复跑：改后连跑两次 `ab-1024-cluster-ci.json` **sha256 逐字节相同**（`cd5fac79…`）。

## 一、为什么做这个（不是拍脑袋）

`exp-8` 已把 P2 的靶子钉死：**向量对 120/120 全部召回**、**中位名次 4,322 / 663,634（前 0.65%）**、
`Top1000` 只覆盖 **30.0%** ⇒ **是"名次"问题，不是"嵌入空间没形成语义邻域"**。

在它之后，**三条路已被量过并堵死**：

| 路 | 实验 | 读数 | 结论 |
|---|---|---|---|
| 列先验（拿属性列当筛子） | `exp-9-col-prior` | 样本内 oracle 上界 **3.04×** < 最低门槛 **4.32×** | 不改 |
| 现成重排器 | `exp-11-rerank-fix` | 主终点 **+1.67pt**、p=0.5、代价 1.10 s/问 | 不接生产 |
| 单纯放大每路上限 | `exp-6-cap` | 候选回池 +10.8pt，**前 20 只 +1.67pt** | 没用 |

⇒ 剩下的是 **查询改写 / 语料内统计关系**。本批做它的**最便宜形式**：**只改查询串**——
索引一个字不动、模型不换、生产代码零改动。若这条能通，代价近乎为零（不重建 663,634 条向量）。

## 四、判决（按预注册阈值机械算，不看感觉）

**⇒ 三条改写全部【不改】。** 逐条：

| 臂 | 落档 | 理由 |
|---|---|---|
| `B1_bge_instruction` | **观察**（+4.17pt < +8.18pt；p=0.0625） | 方向一致（三个阈值全涨、5 进 0 出、中位名次腰斩），但**没到门槛** |
| `C1_domain_prefix` | **放弃**（Δ ≤ 0） | **显著变差**（−6.67pt，1 进 9 出，p=0.0215）⇒ **"自己发明领域前缀"是负面的** |
| `D1_prf_expand` | **放弃**（**向量路**净负；⚠ `fused@20` 未测 ⇒ 不下"对产品净负"的断言） | 主终点 +6.67pt 落"观察"，**但它把 `Vector@20` 从 9.17% 弄到 7.50%** ⇒ **向量路**净负（`fused@20` 本批未跑，见 §五） |

**三条可带走的结论**：

1. **"发明领域前缀"这条路被证伪，且是显著的负效果。** 这与"只做缝合不做发明"（宪法原则 VI）同向 ——
   凭空给查询加一句"检索相关法规与标准条文："**会系统性改变嵌入方向、把正确条文推远**（中位名次 4,322 → 12,244）。
2. **BGE 官方指令前缀是唯一"全阈值同向"的一臂，但收益只有 +4.17pt。**
   ⚠ 值得一提：`bge-*-zh-v1.5` 官方口径是"**v1.5 无需指令**"，实测**加了仍小幅更好**（且**零索引代价**）。
   它**不够格单独接生产**，但可作为**将来与 E4（换模型 / 指令前缀）合并评估**时的一个便宜选项 —— 记在"观察"档。
3. **语料内 PRF 能把"够得着的范围"推远（@1000 +6.67pt、FTS +10.83pt），但把"最前面的名次"弄差。**
   看扩展词就明白：Top-20 伪相关集里挑出来的高频词**多是"进行 / 包括 / 提供 / 系统"这类泛词**
   （见 `per-query.jsonl` 的 `prf_terms`），它们**稀释**了提问里本来就不多的字面信号。
   ⇒ **PRF 这条路的瓶颈是"伪相关集本身不含正确答案"**（gold 中位在 4,322 名）——
   拿"错的邻居"去扩查询，扩得越远越偏。这与 §一 的 `exp-6`（放大上限没用）**互相印证**。

  ⇒ **"等价公式"在名次这种并列敏感的量上不等价**，这是一条通用教训。

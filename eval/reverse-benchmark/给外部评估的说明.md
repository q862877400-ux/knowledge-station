# 请评估：这份「外行问法 ↔ 标准条文」考卷能不能用

> **这份文档是自包含的**，你不需要访问任何代码或数据库。
> **请你判的核心问题**：用这批题去测"检索系统能不能把正确条文找回来"，**结论可信吗**？

---

## 一、背景

**要做的事**：用户用**大白话**提问，系统要在 **52 万条中国国家标准条文**里找到**正确的那一条**。

**已知的困难**（实测数据）：
- 大白话与条文原文**一个字都对不上**的占 **53.0%**（971/1832 条说法）
- 用现成的检索（按字 / 按语义）去测，**排前五的命中率只有 6.8% / 5.8%**

**⇒ 卡点**：现在不知道"找不到"是**哪一环**出的问题 —— 是文档表示、提问表达、检索通道，还是索引本身。**这四种的修法完全不同。**

**⇒ 所以需要一份考卷**：一批「问题 + 正确答案」的配对，用来**定位**问题出在哪一环（而不是只报一个总命中率）。

---

## 二、这批题是怎么造出来的（**请注意第 3 步，它决定了这批题的用途**）

1. **从 52 万条条文里挑"能读出人类问法"的**：长度 30~300 字，且属于
   - **定义形态**（条文以「术语名 英文名 定义正文」开头）—— 47,366 条
   - **要求形态**（含"应/不应/不得/必须"）—— 61,090 条
2. **让模型（Gemini 3.8 Flash）反推**："完全不懂这个领域的外行，会怎么问同一条内容？"
   - 硬约束：**不许出现条文中连续 4 个及以上的字**（防抄原文）
   - 按条文类型分支给指令：定义类只能问"这是啥/怎么分辨"，**禁止**问处罚；要求类反之
3. **让另一个模型（Space Bunny）独立盲判**："这个问法和这条条文配得上吗？"
   - **判定时不告诉它"这是从条文反推来的"**（否则它会顺着说"对"）
   - 每条问法判 3 次（3 个独立实例），取多数

**⇒ ⚠ 这里有一个你必须知道的问题（见第五节缺陷 1）：问法是"看着条文写出来的"，所以这批题带有循环论证的味道。**

## 三、结果

```
生成：110 条条文 → 310 条配对（104 条条文成功）
盲判：171/310 通过 = 55.2%
      其中把握"高" 166 条 / "中" 5 条
可用：171 条
```

**按条文类型差别很大：**

| 类型 | 通过率 |
|---|---|
| 定义类（"X 是……"） | **136/203 = 67%** |
| 要求类（"应……"） | **35/107 = 33%** |

**同一套判定口径下，四条造题路的对比：**

| 造题方法 | 通过率 |
|---|---|
| 正向（先有问法再找条文）· 用生成时贴的术语标签 | 13.4% |
| 正向 · 用向量相似度找候选 | 4.0% |
| 反向 · 用 Space Bunny 造题 | 21.2% |
| **反向 · 用 Gemini 3.8 Flash + 按类型分支** | **55.2%** |

## 五、三个已知缺陷（**评估时请把它们算进去**）

### 1. 循环论证（最重要）

**问法是"看着条文写出来的"⇒ 这批 gold 天然偏向"能读出问法的条文"。**

- **意味着**：用它测召回会**虚高**；而且容易的题偏多
- **缓解**：判定独立（盲判模型不知道来源）；**但循环本身消不掉**
- **我的判断**：这批题适合量"**一条条文能不能被外行问到**"，
  **不适合**直接宣布"系统召回率是 X%"

### 2. 要求类通过率只有 33%（是短板）

**定义类 67%、要求类 33%。** 要求类的问法更难写对，失败样本里常见
「办手续 / 超了没有 / 会不会罚」把话题带偏到别的条文上。

### 3. 判定模型自己有偏

**抽查发现：有的配对其实是对的，却被判"对象不对"。**
例如「平台上挑选代加工厂时显示的质量等级，主要代表啥意思？」配
「云制造服务 QoS 评估」—— 语义上是对的，判成了 FAIL。

**⇒ 所以 171 条是【下界】，不是上界。**

## 六、请你判的四件事

1. **这批题能用吗？** 若能用，**该用它量什么、不该量什么**？
2. **循环论证这个缺陷有多致命？** 有没有不改造题方式就能缓解的办法？
3. **要求类只有 33%，要不要紧？** 如果考卷里定义类占 80%（136/171），
   会不会让"检索系统的表现"看起来比真实情况好？
4. **下一步该做什么？** 我们手上还有：
   - 52 万条条文（全库）
   - 一个只做**暴力精确扫描**的向量索引（**没有近似索引**，所以"索引丢答案"这种情况不存在）
   - 六条召回通道（条款号精确匹配 / 全文检索 / 向量 / 模态 / 法理要素 / 行为客体）
